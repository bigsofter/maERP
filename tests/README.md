# tests/ — автотесты

- **YaXUnit** — юнит-тесты BSL (модульное тестирование общих модулей, бизнес-логики).
- **Vanessa Automation** — сценарные/UI-тесты (feature-файлы на Gherkin).

Структура наполняется по мере появления тестируемого кода. В CI шаг `test` запускает эти наборы на тестовой базе (см. `1c-dev-setup/README-1C-DEV.md`, раздел CI/CD).
