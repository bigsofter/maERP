Порядок расчёта премий

1. В справочнике "Показатели расчёта премий" заполнить показатели с видами "SMART" и "Веса". Остальные показатели являются системными и привязаны к бизнес-логике приложения. Для показателей с видом "Веса" необходимо заполнить вложенные показатели в карточке показателя. Выполнение показателя "SMART" и планы показателя "Планы", а также вложенных показателей показателя "Веса" устанавливается в документе "Установка плановых показателей".
 
2. В справочнике "Варианты расчёта премий" создать существующие в организации варианты расчёта. В таблице указываются показатели и их стоимость.

3. В документе "Кадровый приказ" заполнить данные по окладам, графикам работы, вариантам расчёта премии сотрудников.

4. В справочнике "Формулы расчёта премий" заполнить существующие в организации формулы премий для специфических товаров.

5. В справочнике "Группы номенклатуры" создать списки товаров, по которым будет расчёт с использованием формул расчёта премий. Формула указывается в поле "Мотивация".

6. В документе "Установка плановых показателей" заполнить данные по сотрудникам с указанием плана или стоимости показателя на расчётный период. Для показателя "SMART" нужно вручную установить признак выполнения/невыполнения показателя.

7. В параметрах программы указать % премии по новым и старым клиентам, % профита при отсутствии цен.

8. В параметрах программы указать границу (в рублях) статуса перехода клиента от нового к старому. При расчёте статуса программа учитывает объёмы отгрузок по контрагенту и всех связанных с ним контрагентам.

9. В справочнике "Контрагенты" объединить в группы связанных контрагентов. Для этого в основном контрагенте установить признак "Группа компаний", далее перенести остальных контрагентов в его иерархию.

10. Логика расчёта премии сотрудника выполняется при проведении документа "Реализация товаров и услуг", соответственно при изменении первичных данных описанных выше, необходимо выполнить перепроведение документов в расчётном периоде.

11. Если в номенклатуре установлен признак "Не рассчитывать премию", то по ней премия рассчитываться не будет.

12. Выполнение логики расчёта премии при проведении документа "Реализация товаров и услуг":
- Рассчитывается отношение контрагента к новым или старым клиентам на момент отгрузки, по расчётным данным определяется % от прибыли.
- По товарам реализации программа получает формулы расчёта премий если товары присутствуют в справочнике "Группы номенклатуры".
- Программа получает цены номенклатуры в разрезах "Розничная", "Стоп", "Тип цен" (если тип цен указан в документе "Счёт").
- Рассчитывается себестоимость списанных товаров.

- Если по товару найдена формула расчёта, то премия рассчитывается по ней, где Основа:
Наценка = Сумма продажи - Себестоимость
Профит = 
Стоп цена установлена: Сумма продажи - Сумма стоп
Стоп цена не установлена: Сумма продажи / 100 * % профита при отсутствии цен
Продажа = Сумма продажи

Премия = (Основа / 100 * % компании в формуле) / 100 * % премии в формуле

- Формула не найдена, но продажа по индивидуальному типу цен (согласованные с клиентом цены), то Премия = Доход от наценки + Доход от скидки завода, где:
Доход от наценки = (Сумма продажи - Сумма по типу цен) / 100 * % прибыли для нового клиента
Доход от скидки завода = (Сумма по типу цен - Себестоимость) / 100 * Рассчитанный по клиенту % от прибыли

- Все остальные товары
Профит = 
Сумма стоп = 0 или Сумма продажи < Сумма стоп: Сумма продажи / 100 * % профита при отсутствии цен
Остальные: Сумма продажи - Сумма стоп
Премия = Профит / 100 * Рассчитанный по клиенту % от прибыли
