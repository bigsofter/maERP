Докмуент Изменение цен номенклатуры предназначен для установки цен по определенному прайсу на нужную дату.

Цена устанавливается на начало дня даты документа.

Цена устанавливается для конкретной единицы мзмерения номенклатуры, указанной в табличной части.

В документе есть возможность формирования прайса на основе другого прайса. Для этого необходимо в шапке документа заполнить поле Тип цен основание и указать нужный процент. Кнопка Заполнить по основанию заполнит цены по прайсу-основание, исходя из указанного процента.
