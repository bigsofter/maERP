# src/ — исходники ядра (основная конфигурация)

Сюда кладётся выгрузка **основной конфигурации** в файлы (формат конфигуратора, `DumpConfigToFiles`).

## Как заполнить

На Windows-сервере (где живая база) выполнить `scripts/dump-from-base.bat` — он создаёт папку с XML-выгрузкой. Содержимое этой папки скопировать **сюда** (в `src/`), чтобы получилось, например:

```
src/
├── Configuration.xml
├── Catalogs/
├── Documents/
├── CommonModules/
├── AccumulationRegisters/
└── ...
```

После этого исходники видят: Git, BSL Language Server (линтер), MCP-сервер метаданных (`--dump src`), AI-ассистенты.

> Файлы `.cf` / `.dt` (бинарные) сюда не кладём — они игнорируются Git (`.gitignore`). Нужен именно текстовый XML/BSL-формат.

> Размер реальной выгрузки — десятки тысяч файлов. Это нормально; Git справится. При желании можно сначала залить выгрузку в отдельный «baseline»-коммит.
