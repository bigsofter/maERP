Факты с доказательствами (file:line): `tmp/explainer/facts/01-e01/{1-shell-espaces,2-roles-themes-langs,3-demo-data}.md`.

## Ложные утверждения → исправлено
1. «Портал открывается на Poste opérateur» → после входа открывается **Pouls entreprise** (`/dashboard`, редиректа по роли нет). Сцена 1 показывает Pouls.
2. «Каждое пространство подсвечивается своим цветом» → цвет у всех один; пространства различаются **значком** (компас / грузовик / монеты / пьедестал).
3. «Завтра доступ можно дать бухгалтеру на удалёнке» → убрано: приглашение сотрудника после регистрации в продукте не работает (кнопка-заглушка на /team). Оставлено проверяемое: «в браузере, ставить ничего не нужно».
4. «Оранжевая плашка: 705 рейсов, 645 фактур, 557 CMR» → плашка **голубая**, счётчиков по сущностям нет: одно общее число строк и период (`demo_counts`). Цифры 705/645/557 — старый снимок, сид каждый раз даёт другие.
5. «Кнопка "Supprimer les données de démonstration"» → такой кнопки нет: ссылка **«Les supprimer»** → подтверждение в самой плашке **«Supprimer la démo» / «Garder»**. Поэтому «одной кнопкой» → **«в два клика»**; удалять может только **владелец** — так и сказано.
6. «…остаётся до последней строки» → «всё, что вы завели сами, остаётся» (демо-строка, на которую ссылается ваша запись, тоже остаётся — «до последней строки» звучало бы как обещание полной зачистки демо).
7. «Директор — три пространства» → по умолчанию у владельца **два** (Exploitation + Direction), третье он отмечает сам; «два или три» оставлено. Персонаж назван по роли продукта — **«Владелец»** (не «директор»).
8. «Темы перекрашиваются волной» → в продукте переключение мгновенное; в видео — спокойный кроссфейд, без «волны». «Авто» уточнено по коду: ночная с 20:00 до 07:00.
9. «Палитра: банк, хотя Finance не отмечено» → ✓, но в рейке появляется призрачная секция с бейджем **«по ссылке / de passage»** — показано.

## Имена из кода вместо сценария
- Пространства переведены в каждом языке: ru Эксплуатация / Парк / Финансы / Руководство, en Operations / Fleet / Finance / Management, es Explotación / Parque / Finanzas / Dirección (сценарий оставлял французские).
- «мастерская / l’atelier / workshop / taller» → **ТО и ремонты / Maintenance / Mantenimiento**; «маржа» → **Затраты и маржа / Coûts & marges**; «рейсы» в перечне меню → **Миссии / Missions**; «тратты / letras de cambio» → **Векселя / Efectos / Bills & cheques**.
- Роль диспетчера: fr **l’exploitant**, es **el operador de tráfico** (метки ролей продукта).
- Коммерсант → **Менеджер по продажам** (ru-метка роли). Важно: продажник **видит фактуры** — в видео у него убирается только банк, как и в озвучке.

## Где видео показывает правильную форму, а продукт — нет (см. PRODUCT_BUGS.md)
- ru плашка просрочки фактуры: продукт «Просрочен · N дн.» → в видео «Просрочена · 34 дн.» (фактура — ж. р.).
- Строка счётчика демо-данных: продукт пишет «16405» и ISO-даты → в видео «16 405 · 01.04.2025 → 03.10.2026», как продукт форматирует числа и даты везде.
- Заголовок дашборда — «Pouls de l’entreprise» (заголовок страницы), пункт меню — «Pouls entreprise»; каждый на своём месте.
- Демо-клиенты: вместо CITRUS SOUSS SARL (может быть реальной компанией) — вымышленная OUED SOUSS AGRUMES; CMR в формате продукта CMR-000418; фактуры нумеруются подряд, новые сверху.
