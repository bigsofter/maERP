Product truth
- Switcher = a small button in the RAIL HEADER, right of the wordmark (not in the topbar): espaces icon (2×2 squares) + count in mono + chevron. Click → popup (dark, 196 px real → ≈ 420 px here, radius 10) titled {{ui:web.espaces_menu}} (small uppercase), rows = espace icon + name + check mark on selected. Multi-select: popup stays open. Ticking adds that espace's sections to the rail instantly, no reload. The last ticked espace cannot be unticked (message {{ui:web.espaces_min_one}}) — not shown in this scene.
- Defaults by role: Dispatcher ({{ui:web.team_roles.dispatcher}}) = 1 espace (Exploitation); Owner ({{ui:web.review.owner}}) = 2 (Exploitation + Direction), may tick more.
- The choice is saved server-side in the user's profile → the same selection appears on another device (the portal in a phone browser; it is NOT a native app — draw a phone showing a compact version of the same rail).
- ⌘K (Ctrl+K on Windows) opens the palette: input placeholder {{ui:web.palette_placeholder}}, footer hint {{ui:web.palette_hint}}. Typing {{copy:s03.query}} lists one row: Banque icon + {{ui:web.nav_banque}} + "·" + {{ui:web.espace_finance}} in UPPERCASE small slate. Enter → opens the Bank screen even though Finance is NOT ticked; the rail then shows the Finance section as a GHOST (dashed outline, 0.6 opacity) with the dashed badge {{ui:web.espace_ghost}}.
