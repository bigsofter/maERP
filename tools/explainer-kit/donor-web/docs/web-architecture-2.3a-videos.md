### 2.3а Видео-эксплейнеры (2026-10-02)

Ролики серии (сценарий — `tools/demo-script/explainer/`) лежат в **Bunny
Stream**, библиотека `matransports-explainers`; в репозитории и на прод-машине
их нет — видео, отдаваемое сервером портала, забирает канал у портала.

| Файл | Что держит |
|---|---|
| `components/landing/videos.json` | манифест: CDN-хост и `эпизод → язык → {guid, duration}`. Пишется инструментом публикации серии (`publish.mjs` после рендера), руками не правится |
| `components/landing/videos.ts` | `landingVideo(episode, locale)` → MP4 720p + постер; подписи секции трейлера |
| `components/landing/VideoPlayer.tsx` | серверный компонент: нативный `<video preload="none" poster>` |
| `components/landing/TrailerSection.tsx` | секция `#video` на главной, сразу после «Проблем» |
| `components/landing/videos.test.ts` | каждый опубликованный эпизод есть на всех четырёх языках, длительность ≤ 120 с; у каждого — тексты, `.vtt`, локальный постер и расшифровка |
| `components/landing/videos-library.ts` | видеотека: тексты эпизодов (заголовок-вопрос, «что увидите», три «что вы получаете»), группа, подписи страниц, `videoNav` |
| `components/landing/video-transcripts.json` | озвучка без `{cue}` по абзацам — пишет инструмент серии, руками не правится |
| `public/videos/<slug>/<lang>.{vtt,jpg}` | субтитры и копия постера Bunny — пишет `web_assets.mjs` (его зовёт `publish.mjs`) |
| `app/[locale]/videos/page.tsx`, `videos/[episode]/page.tsx` | видеотека и страница эпизода (`/fr/videos/e01`) |
| `components/landing/VideoCard.tsx`, `RelatedVideos.tsx`, `EpisodeIndex.tsx` | карточка эпизода (общая для видеотеки и страниц функций), блок «Видео по теме», оглавление серии на странице эпизода |

Решения:

1. **Файл на язык, а не субтитры.** Меняются и голос, и титры в кадре. Языки —
   fr/en/es/ru; на арабском `landingVideo` отдаёт `undefined` и секции нет — то
   же правило, что у меню функций.
2. **Нативный `<video>`, ноль JS.** `preload="none"`: до нажатия страница качает
   только постер. MP4 720p (~0,7 Мбит/с) проходит на марокканском 4G; адаптивный
   поток у Bunny есть (`playlist.m3u8`), но вне Safari он требует hls.js.
3. **Два замка, из-за которых бывает чёрный экран.** CSP: `media-src` в
   `middleware.ts` пускает один именованный хост (`VIDEO_CDN_HOST` из того же
   манифеста), не `https:`. Bunny: файлы отдаются только страницам с
   разрешённых referrer'ов — `transport.tinycio.{ma,com,es,ru}`, `localhost`,
   `localhost:3400`; запрос без referrer'а или с чужого сайта получает 403.
   Новый хост лендинга добавляется и в библиотеку Bunny, иначе видео на нём не
   заиграет. Прямая ссылка на MP4 в новой вкладке тоже 403 — делиться надо
   адресом страницы.
4. **Постер** — кадр, который Bunny выбрал сам; сменить можно в библиотеке.
5. **Свой домен на каждый лендинг.** `transport.tinycio.X` берёт видео с
   `video.tinycio.X` (`videoHostFor` по заголовку Host) — посетитель не видит
   стороннего домена, а смена CDN — это смена CNAME, а не перевыпуск страниц.
   Домен попадает в `customHosts` манифеста, только когда инструмент серии
   `video_hosts.mjs` проверил его целиком: CNAME на хост Bunny, бесплатный
   сертификат, принудительный HTTPS и настоящий ответ 206 на MP4. До этого — и на
   localhost/туннелях всегда — видео идёт с хоста Bunny. CSP пускает хост Bunny
   и все проверенные домены из того же манифеста. DNS у доменов разный:
   `.ma` — atakdomain, `.com` и `.ru` — reg.ru, `.es` — Namecheap; запись в
   каждом — `video CNAME vz-bcb32097-72a.b-cdn.net`.

6. **Видеотека `/{locale}/videos` (2026-10-03).** Эпизоды раскладываются по
   тем же категориям, что страницы функций (`FeatureExplorer` переиспользован:
   карточка с `poster` становится видеокарточкой), плюс группа «Знакомство»
   (`intro`) над категориями — решение владельца: часть I сценария (трейлер,
   E01–E03) — это не `demarrage`. Новый эпизод: запись в `LIBRARY`
   (`videos-library.ts`, тексты — из ИСПРАВЛЕННОЙ озвучки и `copy.json` `s07.b1..b3`),
   тест упадёт, если опубликованный эпизод не описан.
7. **Страница эпизода, а не якорь** — `/fr/videos/e01`: свой OG-превью для
   WhatsApp, JSON-LD `VideoObject`, запись в `sitemap.ts`. OG-картинка и
   `thumbnailUrl` — ЛОКАЛЬНАЯ копия постера: Bunny отвечает 403 на запрос без
   разрешённого referrer'а, а роботы WhatsApp/Google его не шлют. Старые ссылки
   `/fr#e01` (эпизод 1 жил на главной под трейлером) переводит на страницу
   эпизода `EpisodeHashRedirect` — якорь до сервера не доходит.
8. **Субтитры WebVTT** строятся из озвучки и `build/<lang>/timing.json` эпизода
   и отдаются с нашего origin (`<track>` с чужого origin требует CORS у Bunny и
   `crossorigin` на `<video>`). По умолчанию выключены — кнопка CC браузера.
9. **Вход в видео:** пункт «Видео» в `LandingNav` (`videoNav`), кнопка
   «Смотреть видео · 2 мин» на первом экране (ведёт на `#video`), ссылка «Все
   видео» в секции трейлера. На арабском нет ни ссылок, ни страниц (404).
   Страницы видеотеки рендерятся динамически: хост видео зависит от домена.
10. **Вся серия в видеотеке (2026-10-04).** 41 эпизод: трейлер и E01–E03 в
    «Знакомстве», остальные — по категории, где живёт ЭКРАН эпизода (как у
    страниц функций): советник E09 и калькулятор E31 — `direction` (экран
    `/advisor`), алерты E22 — `direction`, S1–S6 — `securite`, E33–E36 —
    `demarrage`. Финал сценария вклеен в конец E36 — отдельного эпизода нет.
11. **«Видео по теме» на страницах функций** (`RelatedVideos`, под контентом,
    над CTA): опубликованные эпизоды категории страницы, сначала эпизоды её
    экрана (`PAGE_EPISODES` в `videos-library.ts`), не больше шести, ссылка на
    группу `/{locale}/videos#videos-<категория>`. Постер — ЛОКАЛЬНЫЙ
    (`public/videos/`): страницы функций `force-static` и не знают домена
    посетителя. `featureNav` не меняется.
12. **Видео в Hero страницы функций и навигация эпизода (2026-10-04, владелец:
    «листать в конец неудобно»).** Первый эпизод экрана страницы (`heroVideo`,
    тот же `PAGE_EPISODES`) стоит рядом с заголовком; блок внизу его не
    повторяет. Страница эпизода: хлебные крошки (Главная › Видео › категория ›
    эпизод; пришли со страницы функций по ссылке с `?from=<slug>` — Главная ›
    эта страница › эпизод, канонический URL тот же), под плеером — предыдущий и
    следующий эпизод в порядке серии, слева — плавающее оглавление серии
    (`EpisodeIndex`, `<details>` без JS; на мобильном — под эпизодом).
    Пункт «Модули» убран из верхнего меню: для посетителя это то же, что
    «Функции», и он стал последней ссылкой выпадающего меню (на арабском, где
    меню функций нет, «Модули» остаются в строке).

Ключи Bunny в репозиторий не входят (локальный `tmp/explainer/.env`); баланс
аккаунта отслеживает tiny-monitoring.
