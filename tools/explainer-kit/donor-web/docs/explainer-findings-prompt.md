# Промпт для сессии «доработки портала по находкам видео»

Отвечай по-русски. Работай в своей ветке/worktree от свежего `main`; эта сессия
(видео и лендинг) продукт не трогает.

## Источник

`docs/plans/explainer-findings.md` — ~190 строк: находки сверки 43 видео-эпизодов
с кодом (03–04.10.2026). Структура: основные таблицы A–D (трейлер, E01), раздел E02,
«Пакет 2026-10-03», «Пакет 2026-10-04», дополнение E06. Категории: **A** грамматика и
формы в каталогах, **B** термины, **C** форматирование, **D** поведение и безопасность,
**E** лендинг и сценарии против продукта. У каждого пакета блок «Самое важное».
Доказательства — `tmp/explainer/facts/<эпизод>/` и `tmp/explainer/series/<эпизод>/PRODUCT_BUGS.md`
(в worktree `Видео-для-демо`, не в git): если строки мало, читай их.

Строка удаляется из `explainer-findings.md`, когда исправление выложено (+ запись в `CHANGELOG.md`).

## Порядок (по риску), каждая волна — по процессу `CLAUDE.md`

**Волна 1 — инварианты и безопасность (существенное: план → `ai-review-plan` → … → `ai-security`).**
Сначала перепроверь каждую находку по коду: часть строк записана по отчётам эпизодов без повторного чтения.
1. `client_op_id` новый на каждый клик (форма миссии `lib/mission-draft.ts`, касса, топливо) и формы без
   него вовсе; оплата фактуры без идемпотентности (`invoicing/page.tsx`, `PaymentInput`) — инвариант 7
   (D2, D3, D5, D60; E02/E05/S6/E06).
2. Журналы «только на дозапись» без защиты в БД (нет триггера/REVOKE на DELETE/UPDATE) — инвариант 3 (D26;
   E24 отметил, что роль приложения может удалять строки кассы водителей).
3. Код входа водителя — несолёный SHA-256 от 6 цифр (D12).
4. Сервер не проверяет, что рейсы строк фактуры — её клиента (D33); кнопка «Оплата» по списку ролей,
   а не по праву `payments:write` (D34); отказ по роли выглядит как «модуль не активирован» + триал (D4).
5. Машина «в мастерской» назначается на рейс; правка открытого наряда стирает привязку счёта (D35, D36).
6. HSTS в nginx (D14).
7. Инвариант 2 (позиции вне миссии) — не баг, а не написанный tracking-service (D13): только зафиксировать.

**Волна 2 — деньги и данные (среднее/существенное).**
Сумма выписки без знака читается как поступление (D31); сверка карта↔чек зависит от порядка, откат импорта
не откатывает одометры (D32); «Просрочка/Overdue» = весь долг (D6); «К фактуре» считает выставленные (D7);
перевёрнутый знак в `forecast_integration_test.go:187` (D39); /import без опроса статуса и пункта меню (D37);
экран порогов дашборда отсутствует (D38); остальные D по списку.

**Волна 3 — каталоги (тривиальное/среднее, массово).** Каноническим скриптом ×5 локалей (`AI_GUIDE.md`):
ICU plural везде, где `{n}`/«(s)» (A-строки пакетов), непереведённый французский в ru/en/es
(«Référence DUM», «Péage/Vignette», «Client facturé», серверные строки отказов B28), один термин на понятие
(B-строки: роли, «Миссия/рейс», «Ордера/Платёжные поручения», «оповещение/алерт»), сырой код модуля
`treasury` в подписи (B-E02-1), форматы чисел/дат одним форматтером (C-строки: ISO-даты, «28500.00 MAD»
в PDF, разные форматы денег на разных экранах — **сначала решение владельца**, см. ниже).

**Волна 4 — лендинг против продукта (E1–E12).** _Сделана сессией видео 2026-10-04 (E1–E5, E8, E12); осталась E6 — решение владельца._ Это тексты лендинга (`components/landing/*`, `messages/*/landing*`):
убрать «export à tout moment», «TXT/CSV/Excel», «Марокко или AWS», «перенос из Odoo/Sage существует»,
«CMR en PDF», устаревший «driver-app в разработке», «импорт при регистрации». Согласовать с сессией лендинга
(ветка `bigsofter/Видео-для-демо`), чтобы не править одни файлы параллельно.

## Нужны решения владельца (спросить в начале одним списком)

1. Формат денег: продукт местами по локали интерфейса (en «MAD 33,300», es «33.300 MAD»), местами fr-FR
   «33 300,00» во всех языках. Какой формат — норма? (C-E02-1 и слитые)
2. Цены: `CLAUDE.md` 250 MAD/место + 50 MAD/водитель против кода и лендинга 150 + 30 MAD/активная машина (D30).
3. Банк: лендинг «подключение предусмотрено» против `payment_export.go` «интеграции не будет» (E6).
4. Push-уведомления водителю на французском во всех языках — локализовать сервер или нет.

## Что не трогать

Видео уже показывают ПРАВИЛЬНУЮ форму; исправление продукта перерендера не требует, кроме случаев, где
меняется видимое поведение (например, если «Оплата» станет модальной формой — E23 показывает prompt).
Такие случаи пометь в строке находки «→ видео EXX устареет».
