# Доработки продукта по итогам видео-эксплейнеров

Живой список. Каждый эпизод серии сверяется с кодом построчно (фактчек, вычитка
четырёх языков, аудит) — и по дороге находит места, где сам продукт пишет
неправильно или неодинаково. В видео показывается правильная форма; продукт
здесь **не чинится** — этот документ передаётся отдельной сессии. Строка
удаляется, когда исправление выложено (с пометкой в `CHANGELOG.md`).

Источник каждой находки — папка эпизода в рабочей зоне видео
(`tmp/explainer/series/<эпизод>/PRODUCT_BUGS.md`, не в git) и факты с
доказательствами `tmp/explainer/facts/<эпизод>/`. Новые эпизоды дописывают
сюда свои находки.

Каталоги: `apps/web/i18n/messages/<lang>/*.json`, `apps/mobile/src/i18n/<lang>.json`.
Правки каталогов — каноническим скриптом (см. `AI_GUIDE.md`, ×5 языков).

## Не баги — решено так

- Суммы всегда в формате fr-FR («30 000,00»), даты dd.MM.yyyy — во всех языках
  интерфейса; так рендерит продукт.
- «Авуар» в ru — термин продукта.
- Тема «Авто» = ночная с 20:00 до 07:00 по часам, а не по настройке ОС — по
  замыслу (ночные смены).

### Самое важное из пакета 2026-10-03

Проверено по коду; остальное из пакета — ниже, по категориям.

1. **`client_op_id` новый на каждый клик «Сохранить»** — форма миссии
   (`apps/web/lib/mission-draft.ts:178`), касса и топливо в вебе (D2). После обрыва сети
   повтор создаёт второй рейс или строку; серверная идемпотентность обходится. Инвариант 7. (E05, S6, E02)
2. **Оплата фактуры в вебе не идемпотентна** — `PaymentInput` без `client_op_id`, два
   `window.prompt` (`invoicing/page.tsx:230-243`): повторный запрос = второй платёж (D3). (S6, S3)
3. **Код входа водителя хранится как несолёный SHA-256 от 6 цифр**
   (`passwords.HashToken`, `driver_auth.go`): при утечке таблицы перебор 10^6 тривиален;
   держится на лимите 5 попыток и сроке 24 ч (D12). (S4)
4. **Инвариант 2 («позиции вне активной миссии не принимаются») не реализован** —
   приёма позиций нет вообще (tracking-service не написан) (D13). (S4)
5. **Лендинг обещает то, чего нет в продукте**: «Export à tout moment», файл платежей
   «TXT, CSV ou Excel» (выдаётся только CSV), «export comptable», хостинг «Марокко
   или AWS», перенос из Odoo/Sage, CMR в PDF (E1–E6). (S1, E33)
