# extensions/ — отраслевые расширения конфигурации (.cfe)

Каждая отрасль — отдельное **Расширение конфигурации**, выгруженное в файлы. Расширение зависит от ядра (`src/`), ядро об отрасли не знает.

```
extensions/
├── optical/       # медкарта, рецепты, диоптрии, история очков
├── usedphones/    # IMEI, % батареи, состояние, история ремонта
└── transport/     # маршруты, водители, путевые листы
```

В каждую папку кладётся выгрузка соответствующего `.cfe` в файлы (`DumpConfigToFiles` для расширения). Инсталляция клиента = ядро (`src/`) + нужное расширение.

## Принцип границы «ядро / расширение»

- Нужно ≥2 отраслям → в ядро (`src/`).
- Уникально для одной отрасли → в её расширение.
- Расширение дорабатывает ядро через заимствование объектов и перехват методов (`Перед`/`После`/`Вместо`), добавочные реквизиты и собственные объекты.

> Пока расширения не созданы — это плейсхолдеры. Создаются в EDT/Конфигураторе, затем выгружаются сюда.
