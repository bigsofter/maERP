# E8 — ai-security (обязательный гейт)

**Бэкенд: субагент Claude (opus) по `.ai/prompts/security.md`, не Codex** (лимит Codex до 2026-09-19).

Вердикт: **approve_with_changes**, P0/P1 нет.

Подтверждено: привилегированные процедуры `ПроизводственныеЗаказы` принимают только `ДокументОбъект` (с клиента, из
фонового задания и без права чтения не передать), модуль только серверный, HTTP/веб-сервисов нет; отметка
`ЗапомнитьЗаказыДокумента` перезаписывается в каждой `ПередЗаписью`; `ОбработкаУдаленияПроведения` вызывается платформой
только после проверки права отмены проведения, у 13 документов `unpostInPrivilegedMode=true`; ложную стадию записать
нельзя — расчёт по данным базы; `РассчитатьСтадию` без привилегий вызывается модулем и тестами; `ЭтоЗаказНаПроизводство`
без привилегий — у всех ролей, пишущих реализацию и выпуск, есть `Read` на заказ; секретов в диффе нет.
