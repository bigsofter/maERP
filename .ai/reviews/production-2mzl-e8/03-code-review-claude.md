# E8 — ai-review (обязательный гейт, полный круг)

**Бэкенд: субагент Claude (opus) по `.ai/prompts/reviewer.md`, не Codex** (лимит Codex до 2026-09-19).

Вердикт: **request_changes** — одна P1, три P3.

Подтверждено: пакет расчёта из 10 запросов, индексы 7/8/9; типы и соединения; `ЗаписьСовпадает` по 7 полям; период
записи; наборы блокировок 11 документов перенесены без потерь и в прежнем порядке; пересчёт после `Движения.Записать()`
и всех ранних выходов; по одному обработчику в каждом модуле; продажи — прежнее поведение; колонка `Индикатор` (id
817–819), форма, «Детали», списки реализаций, дашборд, АРМ, кабинет; сценарий `СтадииЗаказа` — все ожидания пересчитаны
по коду и совпадают (1300; 0,6/0,4/0,5385; долги 700/1300/1200; `●●●●◐`, `○○○●○`, −100, `○○○○◐`, `○○●●◐`), остатков
хватает; версия и «Что нового» соответствуют.

| # | Уровень | Находка | Решение |
|---|---|---|---|
| 1 | P1 | `ПроизводственныеЗаказы.ОтменитьПроведениеДокумента`: `УстановитьЗаписьВсехРегистров` наборы не очищает — объект, проведённый и отменённый в одном экземпляре (шаги 4, 6, 7, 9 сценария, программные отмены), записывает движения проведения обратно, стадия считается по ним | **исправлено**: каждый набор `Очистить()` + `Записывать = Истина` перед `Движения.Записать()` |
| 2 | P3 | `ЭтоЗаказНаПроизводство` — лишний запрос на каждый `ОбновитьСтатусЗаказаПоСвязанным` | отклонено: один запрос по ссылке, обработчик обновления разовый |
| 3 | P3 | `ВЫБОР … КОНЕЦ` в `ГДЕ` вместо формы с `ИЛИ` из плана | отклонено как дефект: булев `ВЫБОР` допустим в условии, подтверждается прогоном `doctests` |
| 4 | P3 | «Выполнен» зелёным, в плане серым | план приведён к коду |
