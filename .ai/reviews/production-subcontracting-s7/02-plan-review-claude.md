# S7 — разбор плана (субагент architecture-critic, 2026-09-22)

Бэкенд: субагент Claude `architecture-critic` (Codex в лимите ChatGPT до 26.09.2026).
План: `docs/plans/production-subcontracting-s7.md`, редакция 1.

**Вердикт: approve_with_changes.** Блокирующего нет.

Ответы на вопросы:
1. Форма выбора из оповещения `ПоказатьВыборИзСписка` с владельцем-полем — жизнеспособно: приём уже работает в
   `ВыпускиОтгрузкиПродукцияНачалоВыбора`; форма выбора открывается с `LockOwner`; пустая строка при раннем окончании
   редактирования не записывается (обработчики окончания только ставят «Не записано»).
2. `УстановитьДействие("НачалоВыбора")` в `НастроитьЭлементы` корректно; опечатку в имени ловит только нажатие —
   ручная приёмка на всех четырёх колонках.
3. Параметры выбора поля и реквизита: форма, открытая кодом, параметров реквизита не получает (см. P2-1).
4. Плоский список сделан корректно, побочный эффект — P2-3.

Находки и решения:
- P2-1 (помеченные на удаление в формах, открытых кодом) — принято: `Отбор.ПометкаУдаления = Ложь` явно.
- P2-2 (модифицированность заказа при подстановке из списка) — принято.
- P2-3 (плоский список и в документах с отбором по типу в `.mdo`) — принято: «Что нового», ручная приёмка.
- P3-1 (подбор в записанной строке) — не принято: кнопка выбора ячейки есть только в режиме редактирования, его для
  записанных строк отменяет `ПередНачаломИзменения`.
- P3-2 (режим окна и `ЗакрыватьПриВыборе` явно) — принято частично: `ЗакрыватьПриВыборе` передаётся;
  `БлокироватьОкноВладельца` в 8.5 помечен устаревшим (BSL LS `DeprecatedMethodCall`) — остаётся свойство формы.
- P3-3 (индекс `ДатаСоздания`) — TECHDEBT.
- P3-4 (тестовые позиции с будущей датой) — не принято: сценарий откатывает транзакцию.
