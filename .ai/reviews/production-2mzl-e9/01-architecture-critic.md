# E9 — architecture-critic по плану, редакция 1

Бэкенд: субагент Claude `architecture-critic` (внутрисессионный отсев до обязательного ревью плана).
Вердикт: **approve_with_changes**. Решения по находкам — `.ai/plans/production-2mzl-e9.md`, раздел 12.

## P1

1. **Проба не покрывает проверку заполнения; запись может упасть исключением.** Обязательные реквизиты `ВыпускПродукции`
   (`ТЧТовары`, её `КоличествоУпаковок`/`Количество`, `ТЧГотоваяПродукция.КоличествоУпаковок`/`Количество`, шапка
   `КоличествоУпаковок`); в плане не заполнялись упаковки и коды строк, округление в ноль даёт пустые строки.
   Исправление: заполнять, отбрасывать нули, `ПроверитьЗаполнение()` в пробе. — **принято**.
2. **Блокировки выпуска шире блокировок реализации.** `ВыпускПродукции.ОбработкаПроведения` блокирует `ТоварыВНаличии`
   по номенклатуре без склада; план — по складу; «дозаблокировать» после взаиморасчётов нарушает порядок → взаимоблокировка
   двух реализаций одного контрагента. Исправление: номенклатура автовыпуска как у выпуска, расхождение — отказ. — **принято**.

## P2

3. Серии материалов в партиях под заказ не учтены → ложная недостача. — принято (серии в партиях), общая очередь — TECHDEBT.
4. Серии продукции брать из развёрнутой таблицы. — снято решением владельца: партии в реализацию не ставятся.
5. Себестоимость по позициям многопродуктового автовыпуска приблизительна (веса техкарт). — решение владельца: один выпуск.
6. Формула количества не ограничена временем. — принято: документы раньше реализации.
7. Жёсткий отказ по секунде ломает групповое создание реализаций и соседние секунды. — принято: проба на самом объекте,
   секунда — подсказка к отказу.
8. `ИзОстатка` не видят закупки (`ДефицитЗаказа`, `ОстатокКПоступлению`, пределы). — принято частично, пределы — TECHDEBT.
9. `ДанныеАвтовыпуска` «без записи» против очистки движений. — принято: разделён контракт.
10. Прямое `Удалить()` проведённой реализации оставляет автовыпуск. — принято: `ПередУдалением`.
11. Константа может быть включена в базах клиентов. — решение владельца: не трогать, риск в отчёт.

## P3

Ввод на основании `ПередачаВПереработку` теряет заказ; копирование автовыпуска; удаление непроведённого автовыпуска;
защита экспортных процедур модуля; `ИзОстатка` без свойства стирается; услуги с нулевой себестоимостью; распроведённые
«нечего выпускать» не помечаются; закрытый день у реализации в 00:00:00; противоречие п. 2. — приняты, услуги — TECHDEBT.

## Подтверждено сверкой

`AutoDelete` у реализации; автоудаление при отмене у выпуска; индекс `Основание`; пустой `Хозрасчетный.СформироватьДвижения`;
выход `ОбновитьПроизводственныйСтатусЗаказа` на заказе на производство; одноразовая отметка стадий; граница остатков
`МоментВремени()` проводимого объекта; возврат берёт партии из движений реализации; `ПриходныйДокументПартии` содержит
выпуск; выпусков нет в последовательности `Основная`.
