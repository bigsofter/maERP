# E9 — ревью безопасности, субагент Claude (второй проход по временному правилу владельца)

Бэкенд: субагент Claude `general-purpose` + `.ai/prompts/security.md`. Первый проход — `05-security-review.md`
(`opencode/gpt-6-astra`, временная замена Codex): reject, 1×P0 — пропуск проверки закрытого периода автовыпуска.

**Вердикт: approve_with_changes** — P0/P1/P2 нет; состояние дерева на 14:38 (после исправления закрытого периода).

Главный вопрос: пользователь ролей PDV, Казначей, Оператор, МенеджерПоЗакупкам, ОператорПроизводства не получает
и не меняет данные сверх своих прав: привилегированная запись срабатывает только от объекта реализации, которую он
вправе проводить, параметры берутся из самой реализации и её заказа.

## Находки и решения

| # | Находка | Решение |
|---|---|---|
| P3-1 | `ПодсказкаСекунды` показывает документы других складов и организаций | **исправлено**: отбор по складу автовыпуска |
| P3-2 | `ЭтоЗаписьАвтовыпуска` проверяет только наличие свойства | **исправлено**: значение — реализация, равная основанию |
| P3-3 | экспортные процедуры записи не проверяют `ТранзакцияАктивна()` | **исправлено**: `ПроверитьЗаписьРеализации` в трёх процедурах |
| P3-4 | непроведённый непомеченный автовыпуск удаляется напрямую | **исправлено**: удаление без механизма — только непроведённого помеченного |
| P3-5 | представление реализации в форме выпуска у ролей без чтения реализации | ручная приёмка (TESTING.md «Проверка E9») |

## Подтверждено

`Производство.mdo` — только `server` (не привилегированный, не вызов сервера); `ПроверитьРеализацию` принимает только
объект реализации; реализация проводится и распроводится привилегированно, новая область режима — только `ПриЗаписи` и
`ПередУдалением` реализации над её автовыпусками; режим снимается при выходе из метода; закрытый период проверяется по
ролям текущего пользователя по старой и новой дате автовыпуска; `ДанныеАвтовыпуска` без сумм, только для тестов; ключ
свойства ставит только сервер модуля, форма выпуска его не передаёт; правка, смена основания, ввод на основании,
копирование, удаление проведённого автовыпуска — отказ или безопасное поведение; `ОбменДанными.Загрузка` доступна
только администратору и MobileClient (чтение выпуска); выпуски не в последовательности; права ролей не менялись;
константу меняет только администратор; RLS у ролей нет; секретов в диффе нет.
