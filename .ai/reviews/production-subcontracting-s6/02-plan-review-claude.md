| # | Находка | Решение |
|---|---|---|
| P1-1 | Пересчёт `СуммаНДСУслуг` «по ставке» в `ПередЗаписью` и обработчике затирает ручной НДС (поле редактируемое; демо и сценарии пишут 0 при ставке) и разводит шапку с `ВзаиморасчётыСПоставщиками:108` после обработчика в режиме загрузки | принято: `ПередЗаписью` и обработчик НДС и шапку не трогают; НДС пересчитывается только в интерактивных путях смены суммы |
| P1-2 | У `Кладовщика` есть Posting на поступление (`Rights.rights:5088-5108`), но нет рабочего места; тест 7 упал бы | принято частично: сверено — явное право на рабочее место только у `ОператорПроизводства` (у `Руководителя` его тоже нет, вопреки отчёту). Тест 7 — статическая сверка полного набора прав оператора; ветка «только просмотр» проверяется напрямую `ТекстНетПраваВводаДокументов` не может без роли — оставлена существующей проверкой механизма |
| P1-3 | `ВыполнениеПоПродукции` (`ПроизводственныеЗаказы:244`) считает «Выпущено» с собственным проведённым поступлением → ложный отказ при увеличении количества | принято: необязательный параметр `Документ` (общий текст запроса уже умеет `&Документ`) |
| P1-4 | Транзакция вокруг проведения нового документа ломает запись черновика после отказа | принято: транзакция → отказ → `ОтменитьТранзакцию` → черновик вне транзакции |
| P1-5 | Пересчёт сырья непоследнего поступления передачи не видит более поздних поступлений → перерасход, минус у переработчика | принято: запрет правки и удаления строк, если после документа проведены поступления того же переработчика по передачам того же заказа |
| P2-1 | Сплошная пометка «ручное сырьё» в обработчике — не решение владельца, загрязняет общую базу сценариев | принято: признак ставится только документам, чьё сырьё отличается от `СырьеПоПродукции` на их же границе; обработчик принимает необязательный массив ссылок для сценария |
| P2-2 | Блокировка не покрывает сырьё новой продукции, партии других передач заказа и остаток заказа | принято: `ТоварыВПереработке` по переработчику без номенклатуры, затем блокировка заказа как в проведении; набор — одна экспортная функция документа |
| P2-3 | Пропущены ветки: «Статус → В работу» черновика, `ПрименитьУдалениеСтрок`, `УдалитьСтрокиИзДокумента`, `ТекстЗапросаДокументовДляВыбора`, `ЗаблокироватьЗависимыеДокументы`, `ПозицияСтроки` | принято |
| P2-4 | Тип строки 15.2 шире шапки 12.2 | принято: `DefinedType.СуммаНеотрицательная` |
| P2-5 | `СинхронизироватьСтоимостьУслуг` обнуляет шапку без строк и откатывает правку одной шапки | принято: без строк — не трогать; шапка изменилась против базы и строки её не отражают — перераспределить; иначе сумма строк |
| P2-6 | Тест «строка = документ» на второй передаче — не те же данные; НДС услуг не проверяется (SansTVA) | принято: две одинаковые передачи; ставка 20 % в шаге услуг; сценарии P1-3/4/5, P2-3, P2-5 |
