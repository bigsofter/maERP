## P1 — обязательно до реализации

- **P1-1. Кнопка «Избранное» обходит два действующих запрета РМК.**
  `Form/Module.bsl:25` — `Элементы.Ajouter.Видимость = Не Константы.ЗапретитьРучнойВводТовара.Получить()`
  для роли PDV; `:868` — `Элементы.Ajouter.Доступность = ЭтоНоваяПродажа`.
  Сбой: возврат ручного ввода на кассе «только по штрихкоду»; добавление позиций в уже
  проведённый чек. Зеркалить оба правила и продублировать проверку в обработчике клика.
- **P1-2. Повторный клик по плитке ломается на общем коде.**
  `AfterChoiceProduit` (`Form/Module.bsl:309-323`) при найденной строке не переставляет
  `CurrentRow` и безусловно зовёт `Modifier(Undefined)` (`:76-88`) — открывает редактирование
  произвольной текущей строки. Плюс после каждого клика показывалось бы окно
  количества/цены, что противоречит требованию «клик добавляет товар в чек».
- **P1-3. Цена: «вид цен розничного договора» — неверно.**
  `FormProduitsOnStock/Module.bsl:4-9` — `ТипЦен = Справочники.ВидыЦен.Розничная`,
  переопределяется типом цен **контрагента** (`Параметры.Контрагент.ТипЦены`). Договор не
  участвует. `ПоследнийПрайс` (`ЦеныНоменклатуры/ManagerModule.bsl:2-86`) на одну
  номенклатуру может вернуть несколько строк (измерения `ТоварнаяГруппа, ВидЦены,
  Номенклатура, Характеристика`), а для позиции без цены — ни одной. В чек цена уходит с
  `ЦенаВключаетНДС = Истина` (`:316`) — на плитке показывать ровно её.
- **P1-4. Серия не учтена.** Подбор отдаёт серию из остатков (`Choisir`), плитка не может.
  Есть ФО `ИспользоватьСерииНоменклатуры`.

## P2

- **P2-1. Конструкция плитки.** По модели форм EDT `class Button extends DataItem,
  ExtendedTooltipHolder` — у кнопки контекстного меню **нет** (тезис плана верен); у
  `ДекорацияФормы` контекстное меню **есть** и реквизит формы не нужен. Рекомендация:
  группа-карточка + две декорации-надписи по образцу
  `DataProcessors/Дашборд/ManagerModule.bsl:290-307`, вместо `ПолеФормы` + 80 реквизитов.
  `FormTableType.Cards` на десктопе 8.5.1 недоступен.
- **P2-2. Перестроение после удаления плитки** — сначала элементы, потом команды/реквизиты
  (образец `ЛКП/ФормаНоменклатура/Module.bsl:368-393`).
- **P2-3. Права.** У регистра сведений нет «Добавления»/«Удаления» — только `Read`,
  `Update`, `View`. `Администратор` не трогать: `Roles/Администратор/Rights.rights:3`
  `setForNewObjects = true`.
- **P2-4. Ведущие измерения + `useStandardCommands`** добавляют команды перехода в формы
  `Номенклатура`, `ХарактеристикиНоменклатуры`, `Пользователи`; `menucheck.py` это не ловит.
  Пометка на удаление запись не убирает — нужен отбор.
- **P2-5. Возврат результата.** Подбор отдаёт `Закрыть(Структура)`, а не `ОповеститьОВыборе`
  (`FormProduitsOnStock/Module.bsl:65-66`, `:74-75`); `Характеристики` и `Упаковки` там нет.
  Перехвата события нет (`ОбработкаОповещения` слушает только `"ScanData"`), но пока окно
  открыто в `БлокироватьВесьИнтерфейс`, сканер до РМК не дойдёт.
- **P2-6. Заголовок формы.** `ClientApplicationForm.type` → `ShowTitle` writable: вариант с
  кодом рабочий, ставить в `OnCreateAtServer`. Если править XML — `<showTitle>` встаёт между
  `scalingMode` и `collapseItemsByImportanceVariant` (образец
  `ЛКП/Forms/ФормаЗаявкиНаПоискТовара/Form.form:96-99`).
