## 2. Форма ручного выпуска

### 2.1. Заполнение по техкарте — одним серверным вызовом, через фасад

Серверную часть заполнения переносим из формы в **модуль менеджера `ВыпускПродукции`** (новый `ManagerModule.bsl`, образец —
`Документы.ЗаказПокупателя.ЗаполнитьМатериалыПоТехкартам`) экспортной процедурой
`ЗаполнитьМатериалыПоТехкартам(Выпуск, НесколькоСтрокГП)`: процедура знает табличные части выпуска, а фасад карт остаётся про карты. Тело — тот же код, что сейчас в `ЗаполнитьТехкартуНаСервере` (продукция из
`ТЧГотоваяПродукция` в многострочном режиме, иначе из шапки; фасад на `Выпуск.Дата`; пустой результат — строки не
трогаются; `Загрузить`, `КодСтроки` по порядку) плюс `РаботаСДокументамиКлиентСервер.РассчитатьСтроку` по каждой строке,
которую сейчас делает клиентский цикл. Параметр `Выпуск` — `ДанныеФормыСтруктура` формы или `ДокументОбъект.ВыпускПродукции`:
`Выгрузить`/`Загрузить`/обход строк есть у обоих. Зачем: форма делает одно обращение к серверу вместо 1 + N (+ N при упаковке),
а сценарий уровня 3 проверяет ту же процедуру, что вызывает форма, — на `ДокументОбъект`; вызов на данных формы проверяется
руками (§5).

Изменение поведения: при пустом результате фасада (у продукции нет карты) клиентский цикл раньше пересчитывал `Количество`
уже введённых строк материалов; теперь строки не трогаются вовсе. Безвредно: коэффициент единицы сейчас 1, строка
пересчитывается при своей правке.

Форма: `ЗаполнитьТехкартуНаСервере` — одна строка вызова; клиентская `ЗаполнитьТехкарту` — только вызов сервера (цикл
по строкам уходит).

## 4. `ЕстьВыпускиПослеДаты` без автовыпусков

В обе ветки запроса добавить условие

```
И НЕ (Выпуск.Основание ССЫЛКА Документ.РеализацияТоваровУслуг
	И Выпуск.Основание <> ЗНАЧЕНИЕ(Документ.РеализацияТоваровУслуг.ПустаяСсылка))
```

— то же правило, что `Производство.ЭтоАвтовыпуск` (заполненная реализация). Комментарий функции — «проведённые **ручные**
выпуски; автовыпуск перезаполняется перепроведением реализации». Тексты сообщений в карточке номенклатуры и заказе не
меняются: они и так говорят про ручное перезаполнение. Копия автовыпуска — ручной выпуск по заказу (`ПриКопировании`, E9),
в совет попадает.

## 5. Сценарий уровня 3

Новый сценарий **`РучнойВыпуск`** (24-й, после `АвтовыпускПриОтгрузке`); `ВыпускПродукции` не трогаем.
Данные: остатки M1 (сырьё сценария) 20 по 10, M2 10 по 30; продукция P (продукция сценария, карта M1 2 на дату
сценария) получает вторую версию M1 3 на `НачалоДня(Контекст.Дата) + 2 дня` (два дня — чтобы документы сценария около
полуночи не попали на дату версии); P2 — новая продукция с картой M2 1.

1. **Одна позиция, дата документа.** Выпуск P 5 с посторонней строкой материалов и посторонней строкой P2 9 в
   `ТЧГотоваяПродукция`; `ЗаполнитьМатериалыПоТехкартам(Выпуск, Ложь)` при дате выпуска, переставленной на день второй
   версии, — M1 15; при настоящей дате — одна строка M1: `КоличествоУпаковок` 10, `Количество` 10,
   `КоличествоЗаЕдиницу` 2, `КодСтроки` 1 (посторонняя строка заменена, `ТЧГотоваяПродукция` в одиночном режиме не
   читается). Проведение: M1 остаток 10, P на 100; `Не ЕстьВыпускиПослеДаты(P2, …)` — посторонняя строка P2 ушла при
   синхронизации, отрицательный контроль к шагу 4.
2. **Мультивыпуск.** `ТЧГотоваяПродукция` P 1, P2 2, шапка из первой строки; `ЗаполнитьМатериалыПоТехкартам(Выпуск, Истина)`
   — «M1 2, M2 2», коды строк 1–2. Проведение: M1 8, M2 8, сумма P и P2 на складе 180 (100 + 20 + 60; распределение между
   ними — веса техкарт, отдельно не сверяем, его ведёт `СебестоимостьТехкарт`).
3. **Без карты.** Выпуск товара без техкарты с одной строкой материалов — строки не меняются.
4. **Совет перезаполнить.** `ЕстьВыпускиПослеДаты(P2, НачалоДня(дата))` — Истина (ручной мультивыпуск, P2 не в шапке).

В `АвтовыпускПриОтгрузке`: после `ЕдинственныйАвтовыпуск(…, "первая реализация")` (у P1 только проведённый автовыпуск) —
`Не ЕстьВыпускиПослеДаты(P1, НачалоДня(Контекст.Дата))`; сразу после `ВыпускСтадии` во втором шаге — Истина.

Сценарий регистрируется в `ИменаСценариев` и `СценарийПоИмени`. Ручная проверка в «Проверка E10»: новый выпуск, выбор
продукции — материалы заполнены, `Количество` не 0; режим нескольких позиций с двумя продукциями — материалы по обеим;
товар без карты — строки не меняются.

Реестр: строка в таблице сценариев `docs/TESTING.md`, раздел «Проверка E10», строка в `docs/TESTS.xlsx`.

## 8. Риски

- **Удаление объекта с правами роли**: забытая ссылка — EDT не загрузит конфигурацию. Защита — `rg` по `src/`, refcheck.
- **Реквизит формы `Объект` без `<additionalColumns>`**: форма должна открываться — смок на базе.
- **Перенос колонки из группы**: XML-перемещение узла, id не меняются; дерево формы глазами и дифф.
- **`РассчитатьСтроку` на сервере, на данных формы**: уровень 3 проверяет только `ДокументОбъект` и факт расчёта
  (`Количество` не 0), коэффициент упаковки не проверяет (он сейчас всегда 1); данные формы — ручная проверка.
- **Сценарий на дате второй версии**: `Выпуск.Дата` переставляется только на объекте в памяти, до записи.
