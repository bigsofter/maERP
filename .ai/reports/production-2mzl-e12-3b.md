## Review findings / fixed

- План: запрет правки передачи — по движениям регистра (FIFO по всем передачам переработчика), черновики не запрещают;
  смена основания передачи после поступлений — отказ; цепочка одна: поступление → заказ | передача → заказ; поступление по
  заказу напрямую считается; предблокировка в порядке проведения передачи; индексы `Основание`.
- Код: заполнение поступления — остаток по серии и остаток заказа; нулевая строка не прерывает вычитание; отбор регистра по
  переработчику; предблокировка и материала записываемой строки; представление передачи в выборе — количеством; тексты
  «переработчика»; FIFO-случай в сценарии.
- Проверка: поступление с серией вычитается и из ожидаемой продукции без серии; разделитель поступлений в колонке — «; »
  (запятая есть внутри записи); сценарий проверяет заполнение поступления по второй передаче остатком заказа.

## Findings rejected / deferred (+why)

- Стадии старых заказов не пересчитываются — решение владельца (TECHDEBT).
- Стоимость услуг переработчика скрыта от оператора в форме поступления — решение владельца (TECHDEBT).
- Форма передачи не контролирует остаток партии, проверка смены переработчика в форме без блокировки — прежнее поведение
  документа (TECHDEBT), рабочее место такую передачу не меняет.
- Право оператора на регистры взаиморасчётов с поставщиками и доп. расходов — не из этой сборки, решение по ролям (TECHDEBT).
- Проверка списания выполняется запросом на каждую удаляемую строку передачи, подзапрос выбора без периода — P3, объёмы
  малы (ревью кода P3-4, данных DB-5, частично).
- Правило порядка выпуска и отгрузки — только в рабочем месте; реализации старых заказов после поступлений из переработки
  в рабочем месте не правятся (TECHDEBT).
