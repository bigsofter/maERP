# Отчёт: аналитика загрузки станков для планирования (2.0.16.52, 2026-10-10)

Задача владельца (2MZL, 2026-10-09): «на закладках обработки станков сделай аналитику онлайн по загрузке, облегчающую
планирование, и какие-то отчёты по загрузке». План — `docs/plans/machines-analytics.md`.

## Что сделано

- `ЗагрузкаСтанков.АналитикаЗагрузки` — фонд, работа, обслуживание, занято (без двойного счёта), свободно от момента,
  процент, первое окно заданной длины, узкое место (≥ 90 %), разбивка по календарным дням всего периода. Выведенный
  станок фонда и свободного времени не даёт, его прошлая работа считается.
- `ЗагрузкаСтанков.РискиСрыва` — заказы под риском: запланированная работа по продлённому окончанию, незапущенная с
  сорванным стартом (окончание по рабочему времени от момента), любая незапущенная на выведенном станке, строки
  черновика автоплана с опозданием или без окна; дефицит мощности нарастающим итогом по датам отгрузки в горизонте
  (потребность — полный черновик и незапущенная работа, мощность — свободные часы действующих станков).
- `ЧасыРаботыВРабочееВремя` обобщена видом записи; строка автоплана без окна получает часы — минимум по станкам.
- АРМ «Управление станками»: поле «Окно не короче, ч», страницы «Загрузка» (тепловая карта 14 дней, подвал свободных
  часов, подменю «Отчёты») и «Под риском» (риски и дефицит; расчёт при открытии страницы, по «Пересчитать», сразу при
  обновлении открытой страницы; «Автоплан» передаёт свой черновик). Форма — генератор `scripts/formgen/machines-analytics/gen.py`.
- Отчёт «План загрузки станков» (варианты «По дням», «Заказы под риском»), права `ОператорПроизводства`, меню
  «Производство → Станки», опция «Учёт станков». Схема — `scripts/formgen/machines-analytics/report.py`.
