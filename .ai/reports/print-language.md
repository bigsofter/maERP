# print-language — 2.0.16.18

Задача владельца 2026-10-06: тумблер «Язык» в окне печати, по умолчанию язык сеанса; печатная форма перестраивается
по синонимам выбранного языка в уже существующих макетах, без копий форм.

Ключевой факт из проб на 8.5.1 (внешняя обработка на build/ib): `КодЯзыка` у готового табличного документа стирает
многоязычные подписи; работает только `Макет.КодЯзыка` до `ПолучитьОбласть`. Первая реализация (смена `КодЯзыка` у
результата) поэтому отброшена; язык доводится до `МакетПечатнойФормы` через контекст вызова (`ПечатныеФормыПовтИсп`),
формы при переключении формируются заново. Урок — правило tiny1C `tmpl-002`.
