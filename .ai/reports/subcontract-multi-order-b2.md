## Найдено и исправлено проверками

- Заполнение общей передачи: документ собирается и проверяется под исключительной блокировкой заказов; изменившиеся за
  время диалога данные — отказ «данные изменились», а не запись устаревшего.
- Порядок блокировок «заказы → регистры» на всех путях записи передачи (АРМ, заполнение, «Статус», форма документа).
- Выпущенные ПФ — общий уменьшаемый пул по продукции; переданное учитывается по продукции.
- Смена заказа строки общей передачи: количество ПФ/ГП по норме пересчитывается по новому заказу, а не сохраняется как
  ручное.

## Принято без исправления

- P2 ai-database «запросы по каждому заказу»: заполнение выделяет единицы заказов (выбор в диалоге), цикл по заказам
  дешевле общего запроса с разбором дерева состава.

## Не покрыто автотестами — проверка руками

- Способ «по выпущенным ПФ» (нужен выпуск ПФ в демо-данных).
- Диалог заполнения на клиенте (смок открывает форму, но не проходит шаги).
- «Статус» общих документов — только в форме документа.
