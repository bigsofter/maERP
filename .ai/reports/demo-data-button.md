# Кнопка «Заполнить демо-данными», повторный запуск демо-набора и блок станков — 2.0.16.47 (2026-10-09, 2MZL)

Задача владельца 2026-10-09: кнопка в «Настройка → Параметры → Компания и учёт», запуск на базе с уже загруженным
демо-набором с переиспользованием «такого же», блок учёта станков с данными во всех отчётах. Решение владельца по ходу:
кнопка работает только в демо- и тестовой базе, на базе с рабочими документами — отказ. План —
`docs/plans/demo-data-button.md` (семь редакций; находки ревью и как закрыты — в плане).

## Сделано

- `Обработки.ТестовыеДанные`: проверка демо-базы `РабочийДокументБазы` (любой документ любого вида без маркера
  демо/образца/теста, кроме автовыпусков, выпусков по требованию, техкарт демо-номенклатуры и заявок набора; запрос
  строится по метаданным); справочники — «найти или создать» по ключам (номенклатура — артикул `DEMO-2MZL-…`, для старого
  набора — наименование + демо-единица с дописыванием артикула); документы — только по ключу `Démo 2mzl #<блок>-<кейс>-<n>`
  (`ЗаписатьДокументКейса` ставит его последним); кейс атомарен (все — переиспользован, ни одного — создаётся своей
  транзакцией, часть/пометка/повтор ключа — «неполный»); признак поколения `#RUN-v2`, старый набор — ядро целиком;
  предусловия по остаткам; P11 не пишет поверх существующей версии карты; блок M (три станка, 14 документов, факт в
  трёх последних завершённых сменах E1, инвентаризация до следующего запуска, второй заказ для «Готовых к запуску»).
  API: `НовыеПараметрыДемоНабора`, `СоздатьДемоНабор(Параметры)`, `ЗаполнитьДемоДанные`, `ЗаполнитьДемоНабор` (контракт
  сценария `ДемоНабор` сохранён), `ЭтоРабочийДокумент`, `ТекстОтказаДемоНабора`. Право «Администрирование» проверяется
  на входе `СоздатьДемоНабор` и `ЗаполнитьДемоДанные`.
- `НастройкиПрограммы/КомпанияИУчёт`: группа «Демо-данные» (только администратору), флажки опций и блока станков,
  проверка базы до подтверждения, `ФоновыеЗадания.Выполнить` с ключом «ДемоДанные» (образец `ПерепроведениеДокументов`),
  опрос раз в секунду, итог на 4 языках. Фоновая процедура — `ПроцедурыРегламентныхЗаданий.ЗаполнитьДемоДанные`.
- `СмокТест`: режим `ТестовыеДанные;<отчёт>;Демо;Станки`; `scripts/fixtures.sh --demo [--machines]`, строки
  `ПЕРЕИСПОЛЬЗОВАН/НЕПОЛНЫЙ/ПРОПУСК/ИНФО/ОТКАЗ`.
- Тесты уровня 3: `ДемоНаборПовтор`, `ДемоНаборОтказ`, `ДемоСтанки` (66 сценариев); `docs/TESTING.md`, `docs/TESTS.xlsx`,
  `docs/TECHDEBT.md` (сломанный `ДлительныеОперации.ВыполнитьВФоне` и др.), `docs/ROADMAP.md` (следующие блоки V, A, N, D).

## Осознанно (TECHDEBT)

- Даты запрета для блока M не проверяются заранее (функция не экспортная) — запрет откатит кейс M с ошибкой проведения.
- Помеченный на удаление справочник набора останавливает прогон с `ОШИБКА;Справочники`.
- Гонка с пользователем демо-базы по демо-остаткам — принятый риск.
- Валюта, тендер, налоговая накладная, доп. расходы в демо-наборе — следующие сборки (ROADMAP).
