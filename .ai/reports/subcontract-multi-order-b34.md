## Найдено и исправлено проверками

- Ревью плана: выпуск без заказа — общий валидатор требовал продукцию в заказе и организацию заказа; «Завершить»
  требования — путь рабочего места станков с вводом факта; ожидаемое у подрядчиков — не только по передачам с остатком.
- Ревью кода: «Провести» выпуска без заказа отклонялось из-за сравнения основания `Неопределено` с пустым заказом;
  ожидаемая продукция «У подрядчиков» шла без заказа и клиента; «Завершить» из режима «Строки» предлагал количество
  материала; склад записанного выпуска можно было поменять в таблице без записи; отбор по складу в «У подрядчиков» не
  действовал.
- Тест: «Завершить» с закладки в ту же секунду, что запуск, проведение требования отклоняет — тест ставит факт на
  датах сценария.

## Принято без исправления (TECHDEBT «Закладка «Документы» рабочего места производства»)

- Ожидаемая продукция по каждой передаче до выделения страницы («Только незакрытые», «У подрядчиков»): объём
  ограничен периодом, пакетный расчёт — в очереди производительности (ROADMAP, блок 9).
- «У подрядчиков» не видит старых передач без остатка сырья вне периода.
- «Завершить» из режима «Строки» предлагает 0.

## Не покрыто автотестами — проверка руками

- Вид закладки на клиенте: скрытие нижних закладок, колонки и команды по виду и режиму, пагинатор.
- Двойной щелчок, «Поступление из переработки» (открытие формы), меню «Печать».
- Ввод выпуска без заказа в таблице: добавление, удаление, отказ без основной организации.
- Вопросы «Отменить» и «Вернуть в работу» у требований, «Вернуть в работу» (право руководителя).
