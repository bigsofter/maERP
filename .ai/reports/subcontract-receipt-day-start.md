# 2.0.16.145: поступление из переработки на дату начала дня

**Симптом (владелец, 2026-11-04).** Новое поступление из переработки по передаче, проведённой сегодня, сообщает:
«Сырья этой передачи у переработчика на дату документа нет». После смены даты документа заполняется.

**Причина.** Новый документ из формы платформа датирует началом текущего дня, а время ставит при записи.
`Документы.ПоступлениеИзПереработки.ГраницаОстатков` брала остатки на `Граница(Дата, Включая)` = 00:00:00,
и передача, проведённая позже в тот же день, в остатки не попадала.

**Исправление.** У нового документа дата, равная началу сегодняшнего дня (или пустая), читается как
текущий момент сеанса — `Граница(ТекущаяДатаСеанса(), Включая)`: включительно, чтобы не терялись движения
текущей секунды (находка ревью, P2).

**Тест.** Сценарий `Переработка`, шаг `ПроверитьЗаполнениеПоступленияНаНачалоДня`: поступление с датой
начала сегодняшнего дня заполняется по сегодняшней передаче.
