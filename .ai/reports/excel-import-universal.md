# Отчёт: excel-import-universal — сборка 2.0.17.7 (универсальная загрузка из файла)

Дата: 2026-11-10. План — `docs/plans/excel-import-universal.md` (волна 3 мастер-плана `retail-chain.md`, этап У3
`docs/UNF-ADOPTION.md` — частично).

## Что сделано

- Общий модуль `ЗагрузкаИзФайла`: чтение xlsx/xls/ods (платформа) и csv/txt (UTF-8, разделитель по первой строке,
  кавычки RFC 4180, пределы размера файла, строк, колонок и длины значения); описание приёмника (ТЧ с номенклатурой,
  классы «количество» и «сумма», явная карта подчинённых ТЧ, перечень исключённых); автосопоставление заголовков;
  преобразование строк с пакетным поиском (номенклатура по штрихкоду с характеристикой и серией, артикулу, коду
  поставщика, коду, наименованию; характеристика и серия - только среди элементов товара строки; прочие справочники и
  перечисления); единое заполнение `ЗаполнитьТЧ` в копии ТЧ (умолчания только для несопоставленных полей, пары
  количеств, цена тем же путём, что форма, пакетом цен, коды строк max+1, отказ при проведённом документе и при замене
  со связанными строками); `ЗагрузитьВДокумент` - запись под правами пользователя в транзакции со сверкой версии и
  проверкой заполнения; создание товаров - после разбора, только для строк без ошибок, атомарно на товар.
- Обработка `ЗагрузкаИзExcel` переименована в `ЗагрузкаИзФайла` (тот же uuid), форма переписана: выбор документа и ТЧ,
  файл, строка заголовка, сопоставление колонок, правила поиска, создание товаров, проверка (предпросмотр с ошибками),
  настройки загрузки с быстрым выбором последних пяти.
- Справочник `НастройкиЗагрузкиИзФайла` (автор - текущий пользователь, общие или личные; RLS: чтение «общие или свои»,
  изменение - свои).
- Общая команда «Загрузить из файла» для 22 документов с приёмниками; кнопка загрузки шести документов переведена на
  движок (пустой результат не очищает ТЧ, упаковка и ставка из файла сохраняются, проведённый - отказ).
- Права: обработка, справочник с RLS и команда - Руководитель, МенеджерПоПродажам, МенеджерПоЗакупкам, Кладовщик,
  Оператор, Логист, СкладскиеОрдера, ОператорПроизводства.
- Тесты: `ЗагрузкаИзФайлаЧтение`, `ЗагрузкаИзФайлаДокумент`, `ЗагрузкаИзФайлаКлассы`, `ЗагрузкаИзФайлаЗапреты`,
  `ЗагрузкаИзФайлаНастройки` (184 сценария).

## Проверки

| Гейт | Результат |
|---|---|
| `ai-review-plan` | 13 кругов; круг 13 - approve_with_changes (P2 внесён). Круги 7-9 по ошибке прогнаны на неизменённом плане (правки не применились), их находки внесены в круге 10 |
| `ai-review` | круг 1 - reject (3 P1, 2 P2): выбор ТЧ в режиме формы, заголовок настройки с номером, проведённый документ через кнопку формы, создание товаров до проверок, аргумент `ОписаниеТипов` в тесте - исправлены. Проверка 1 - approve_with_changes: 4 fixed, 1 partially_fixed, 2 новых P2 (характеристика нового товара, числовой префикс в заголовке) - исправлены. Проверка 2 - «not_fixed» по находкам, закрытым в проверке 1, - артефакт инкрементальной дельты |
| `ai-security` | approve_with_changes, P2 - пределы размера файла и разбора CSV - исправлено |
| `ai-final-check --db` | 8 из 8 |
| Смок | 423 формы, 0 ошибок |
| ТестыДокументов | 184 сценария, 0 ошибок (новые - 5 загрузки; разовый сбой `ПроведениеЗаказа` на функциональной опции в промежуточном прогоне не повторился) |

Отклонено с причиной: P2 «создание товаров не в одной транзакции с применением загрузки» - состояние документа,
связанные строки и все значения строк проверяются до создания товара; созданный товар - законный элемент справочника,
который пользователь и так создавал этим режимом; общая транзакция «товары + документ» для формы документа невозможна
(ТЧ формы заполняется после закрытия обработки). Остаточный случай - конфликт версии документа при записи.

## Не проверено

- EDT: синтаксический контроль и ссылочная целостность - у владельца после Refresh.
- Клиент: выбор файла (диалог помещения файла), форма загрузки, общая команда из формы документа и списка,
  перечитывание формы-владельца, xls/xlsx на macOS, RLS личной настройки под двумя пользователями - регресс человека.
- Путь данных формы документа (`ЗаполнитьТЧ` на данных формы) и подбор цены закупки без ценовой колонки -
  автотестом не покрыты (TECHDEBT 2.0.17.7).
