# 2.0.16.108 — режим «Товары» на закладке «Поступления» рабочего места закупок

План: `docs/plans/arm-purchasing-receipt-lines.md` (редакции 1–6). Клиент — Drissotex.

## Сделано

- Переключатель «Документы / Товары»; таблица `ТоварыПоступлений` — строки документов текущей страницы.
- Запись строки при выходе из неё (обработчиком ожидания): новая строка — новое поступление по первой открытой строке
  заказа поставщика на товар или без заказа; выбранный сегодняшний документ — по его заказу (свободный код строки) или
  без заказа; смешанных документов нет. Ордерный склад — приходный ордер (механизм `АРМПроизводство`).
- Механизм: признак `БезЗаказаПоставщику` (новая строка без заказа — только при отсутствии открытых строк заказов
  поставщика по товару), равенство незаполненных оснований любого типа, `СтрокиДокументовСписка` (поступления и ордера
  одним пакетом, права раздельно, строки по ордеру — просмотр).
- `АРМЗакупки`: `ОткрытыеСтрокиЗаказовПоставщика` (расчёт «К поступлению» без предела 500), `ЗаписатьСтрокуТоваровПоступления`,
  `УдалитьСтрокиТоваровПоступлений`, `СтрокиТоваровПоступлений`, `ДокументыДляСтрокиТоваров`.
