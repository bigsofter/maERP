## Что сделано

- Форма списка потребностей: динамический список с запросом (запрошено из строк, принято / отгружено / получено из
  регистра, состояние исполнения, просрочка по желаемой дате; параметр начала дня обновляется раз в час). Текст
  запроса — общая функция модуля менеджера (используется формой и тестом). Роль точки читает регистр с RLS по точке.
- «Заполнить по анализу» (команда черновика): рекомендации по строкам «товар + характеристика» из продаж за период,
  остатка, «в пути» и открытых потребностей; нормативы склада — на товар целиком; привилегированное чтение после
  проверки своей точки. Настройки склада «Дней запаса», «Дней анализа продаж».
