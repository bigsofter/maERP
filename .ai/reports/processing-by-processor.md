  «переработчик → заказ передачи» (схема компоновки, отборы переработчик/клиент/заказ), секции бок о бок «Передано»,
  «Принято», «Остаток у переработчика» со старейшей передачей и днями.
- Заказ группы — по передаче (`ПередачаВПереработку.Основание`), не по измерению движения: историческая асимметрия
  заказов из обработчика волны 12.
- Смешанное поступление (сырьё нескольких заказов) — полностью в каждом заказе с «◐», в итог переработчика — один раз;
  признак смешения считается до отбора групп. Хвосты без сырья — в «Принято» с пометкой, вне среднего срока.
- Средний срок — по парам «поступление — передача» без веса количеством; старейшая незакрытая передача — дней на
  конец периода. Итоги — по единицам, характеристика — в строках.
- Права `Кладовщик`; сценарий уровня 3 `ПереработкаПоПереработчикам`; версия 2.0.16.129; «Что нового» ru/fr/en/es.
