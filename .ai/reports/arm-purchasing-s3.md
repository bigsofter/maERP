# Отчёт: рабочее место закупок — «Потребность» (2.0.16.30)

План — `docs/plans/arm-purchasing.md`, раздел «Сборка 2.0.16.30». Решения владельца 7–10 приняты 2026-10-07.

## Сделано

- Закладка «Потребность» стоит первой.
- Источники строк:
  - материалы заказов клиентов на производство на стадии до выпуска (последняя запись стадии в истории);
  - пополнение до минимального остатка складов с оповещением. Правило то же, что у регламентного оповещения; из
    остатка исключены партии, пришедшие под заказы.
- Дефицит строки производства — «Потребность − Макс(Заказано, Пришло) − ИзОстатка» по продукции. Поступление прямо под
  заказ клиента дефицит закрывает.
- Группировка по товару (по умолчанию), по заказу клиента или по поставщику. Флажок «Только с дефицитом». Внизу —
  источники, заказы поставщикам по товару, остатки по складам. Цена — последний прайс основного поставщика.
- «Заказать»:
  - отдельный заказ поставщику на каждый заказ клиента (решение 10) и один заказ на пополнение; излишек уходит в
    пополнение;
  - запись — пакетом `Обработки.АРМПроизводство.ЗаписатьСтрокиЗаказа`;
  - под блокировкой дефицит перечитывается той же функцией, что строит экран: строка под заказ клиента урезается до
    дефицита и раскладывается по изделиям с явной продукцией, пополнение при уменьшившемся дефиците получает отказ;
  - строка без поставщика получает отказ;
  - строка, у товара которой есть черновик заказа поставщику, получает отказ.
- Сценарий `ПотребностьЗакупок`. Версия 2.0.16.30, «Что нового» на ru, fr, en и es.
