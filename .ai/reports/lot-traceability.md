## Что сделано

- Отчёт `ПрослеживаемостьПартий` (раздел «Производство», опция переработки, общая форма отчёта): партии материала
  первичного прихода (схема компоновки, отборы пользователя), воронка — пакет запросов модуля объекта, вывод четырьмя
  секциями бок о бок: партия материала → выпуск ПФ → передача в переработку → отгрузка заказчику с «На складе».
- Лот — номер документа поставщика; у приходного ордера — построчно по материалу через `ДокументИсточник` и
  `ТоварыКОформлению`, без номера поставщика — номер поступления, без оформлений — «ордер № (не оформлен)».
- Смешение партий (выпуск по полному ключу партии материала, поступление из переработки по полному ключу сырья,
  наследование по цепочке) — пометка «◐», количества долями не делятся.
- Отгрузки — нетто по документу закрытого списка (реализация/расходный ордер, возврат с минусом), прочее выбытие —
  отдельными строками и итогом; итоги по единицам измерения; отбор по клиенту — по клиенту каждой секции, «На складе»
  при отборе не выводится; хвостовые поступления без сырья — справочно, вне воронки.
- Права — `Кладовщик` (как у «Товаров в переработке»), остальные — через `setForNewObjects`.
- Сценарий уровня 3 `ПрослеживаемостьПартий`; версия 2.0.16.128, «Что нового» ru/fr/en/es.
