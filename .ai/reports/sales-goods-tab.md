# sales-goods-tab — закладка «Товары» в списке расходных накладных (2.0.17.35, тикет 2605528)

План: `docs/plans/sales-goods-tab.md` (редакции 1–11 с правками по кругам ревью).

## Что сделано
- Модуль менеджера `РеализацияТоваровУслуг`: `СтрокиТоваровСписка` (строки последних 200 документов по отборам панели,
  признак «только просмотр»), `ЗаписатьСтрокиТоваров` (пакет строк одного документа: блокировка, версия, правила правки,
  новая реализация с шапкой как в форме — головной контрагент, договор, вид цен, валюта договора; цена — функциями формы
  документа, упаковка восстанавливается, расчёт от цены сохраняет процент скидки; ручная цена — при заверении цен и в
  валюте документа; сообщения подстановки цены — отказ), `УдалитьСтрокиТоваров` (документ без строк — пометка по праву
  интерактивной пометки, неизменённым объектом), `ДокументыДляСтрокиТоваров`, `ШапкаДокументаСтрокиТоваров`,
  `ЗначенияНовойСтрокиТоваров`. Правятся только простые реализации (без основания, кассы, услуг/доп. расходов/авансов,
  ордеров, серий, налоговой накладной — последняя проверяется узким привилегированным запросом).
- Ограничения ролей: цены и суммы скрыты от роли со скрытыми ценами (`ФирменнаяПечать.ЦеныСкрыты`) вместе с отборами по
  сумме и долгу; PDV — только свой склад (пустая настройка — ничего); «Клиент» — только свой контрагент.
- Форма списка: закладка «Товары», таблица значений, ввод по образцу АРМ закупок (вставка сверху, запись обработчиком
  ожидания, очередь пакетами по документу, незаписанные правки переживают перечитывание и смену отборов, отмена правок
  — только «Обновить» с вопросом), выбор документа, двойной щелчок, удаление, «Печать» из доступных команд печати
  реализации по выделенным строкам, сортировка из контекстного меню, закрытие формы с незаписанными правками — вопрос.
- Тест `РеализацииТоварамиСписка`; `docs/TESTING.md`, `docs/TESTS.xlsx` (350 сценариев); TECHDEBT/ROADMAP.
