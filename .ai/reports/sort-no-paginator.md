# Сортировка кликом по колонкам: снят собственный пагинатор (2.0.17.8)

Запрос владельца 2026-11-10: в рабочих местах производства и закупок и в списке КП не работает сортировка по клику
на колонку; в списке заказов покупателей — тоже. Решение владельца: вариант А — собственный пагинатор убрать.

## Причины

1. Пагинатор 44 списков документов и обоих рабочих мест: страница — отбор «Ссылка В списке» из 50 документов,
   выбранных по дате; клик сортировал только их.
2. Девять динсписков (КП, приходные и расходные ордера, список заказов АРМ производства, вторичные списки) без
   `ListSettings.dcss`: порядок не входил в пользовательские настройки.
3. АРМ производства: порядок по дате ставился в `Заказы.Порядок` — фиксированная настройка впереди пользовательской.
4. Таблицы на значениях рабочих мест — `changeRowOrder` = false.

## Что сделано

- 44 формы списков: сняты `ПрименитьСтраницу`, команды и реквизиты страниц, группа пагинации; возвращена штатная
  полоса состояния. Все отборы панели уже стояли в `Список.Отбор` — сверено скриптом по каждой форме.
- 9 динсписков получили `ListSettings.dcss`; у списка заказов АРМ производства порядок «Дата убыв» — в нём.
- АРМ производства: пагинатор заказов и закладки «Документы» снят; `СтраницаЗаказов` → `КоличествоЗаказов`
  (для тестов отборов); `ДанныеЗакладкиДокументов` без страниц. Группа с легендой — `ГруппаЛегенда`.
- АРМ закупок: `ДанныеЗаказов`, `ДанныеПоступлений` вместо постраничных функций; `changeRowOrder` у таблиц обоих АРМ.
- `РаботаСДокументамиКлиентСервер`: удалены функции пагинатора.
- Тесты `ТестыДокументов` переведены на новые функции; реестр, FORMS-STYLE, TECHDEBT, «Что нового» 2.0.17.8.

## Проверки

- BSL LS против baseline `HEAD`: новых замечаний нет; refcheck, listcheck, queryfields, colfont — чисто.
- Копия `build/ib` 2.0.17.7 → синхронизация из `src/cf`: CheckConfig без ошибок, смок 423 формы / 51 печатная /
  69 вариантов отчётов — 0 ошибок; `doctests` 184 сценария — 0 ошибок.
- Ревью Codex: 1 находка P2 (квадратичный поиск ранга документа в `СтрокиТоваровПоступлений` при неограниченном
  списке) — поиск переведён на соответствие; неограниченная загрузка — следствие решения владельца, в TECHDEBT.
- Не проверено: сортировка кликом глазами на клиенте 8.5 (в том числе вывод, что таблицы на значениях сортирует
  `changeRowOrder`); EDT Refresh и проверка — у владельца.
