# Отчёт: exchange-maerp-62 — сборка 2.0.17.19 (обмен между базами: HTTP и диспетчер)

Дата: 2026-11-12. План — `docs/plans/exchange-maerp.md`, раздел «6.2 в реализации» (2.0.17.18 занята потоком саппорта;
6.2 разделена на 2.0.17.19 и следующую сборку, восстановление пары и мастер — после волны 7 по решению владельца).

## Что сделано

- **HTTP-сервис `ОбменМеждуБазами`** (`/exchange/message/{Код}` POST, `/ping/{Код}` GET): допуск до чтения тела — право
  на метод шаблона URL (роль `ОбменМеждуБазамиСервис`), узел по коду, привязка технического пользователя ИБ к узлу
  (`ИдПользователяСервиса`, один пользователь — один узел), включённость, Content-Length; затем HMAC-подпись пакета
  ключом пары, захват узла (занят — 409), пакет `{ACK, Сообщение}`, подписанный ответ.
- **Транспорт HTTP у инициатора**: только `https://` (проверка при записи узла и перед соединением), проверка
  сертификата по корневым ОС, Basic из `УчетныеДанныеОбмена`, перенаправление — ошибка, ответ без подписи — ошибка,
  до 20 пакетов за запуск.
- **Регламентное задание-диспетчер** раз в минуту: события, сверка состава, входящие файлы каталога, опрос
  HTTP-инициатора не реже 15 минут; включается/выключается при записи узла, обработчик обновления 2.0.17.19
  включает его для узлов 2.0.17.17.
- **Форма узла**: адрес, инициатор, пользователь сервиса (назначает только администратор — проверка и на сервере),
  логин/пароль партнёра (пароль на форме не остаётся; смена адреса стирает сохранённые логин и пароль),
  «Проверить подключение».
- **Правки 6.1 по ревью плана**: коэффициент единиц для отдельной позиции (регистр `СопоставлениеЕдиницОбмена` +
  измерение `Номенклатура`, монитор — колонка «Только для товара»); цена установки цен из обмена — за базовую
  единицу, положительная цена, округлившаяся до нуля, — в отложенные; дата запрета обмена учитывает автозакрытие.
- Раннер тестов документов пишет файл прогресса (`<отчёт>.progress`): при обрыве клиента виден сценарий.
- Тесты: 7 новых сценариев (299 всего).
