## Review findings / fixed

- План: продукция строки заказа поставщику — пустая (распределяет регистр); поступление выбирает строку заказа поставщику
  (код строки); цена основания приводится к упаковке и режиму НДС; строки с сериями, документы с услугами, доп.
  расходами, авансами, завершённые — только в форме документа; повтор записи свежим объектом, проведённый документ при
  отказе не понижается; номер накладной — ключ подбора документа; запреты для строк заказа поставщику с поступлениями.
- Код: проверка пришедшего и запись заказа поставщику — в транзакции под блокировкой потребностей заказа, пришедшее
  проведённое — по движениям «Заказы поставщикам»; «Статус» заказа поставщику с поступлениями — отказ под той же
  блокировкой; подстановка документа — только за сегодня и по накладной, дата следует за номером; поступление без заказа
  поставщику при открытой строке — отказ; розничная и минимальная цена прежнего материала обнуляются; повтор проверки
  документа после блокировки; «Статус» — только документы текущего заказа; характеристика — этого материала; строка
  без правок не блокирует документ; отвергнутая правка откатывается; пустой документ помечается свежим объектом.
