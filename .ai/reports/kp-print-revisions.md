# Отчёт: редакции и печатная форма коммерческого предложения (2.0.16.50–2.0.16.51, 2026-10-09…10)

Задача владельца (2MZL): редакции КП во времени (v1 → v2 → v3), просмотр и перепечатка ушедшей клиенту редакции,
возврат редакции, собственная печатная форма КП с логотипом организации. План — `docs/plans/kp-print-revisions.md`.

## Что сделано

2.0.16.50 (2026-10-09, временный CF выдан владельцу 2026-10-10):
- Регистр сведений `РедакцииКоммерческихПредложений` (снимок: содержимое для возврата + самодостаточные данные печати,
  SHA-256 значимого содержимого), реквизиты `Версия`, `ИзмененоПослеРедакции`; номер редакции растёт при записи
  изменённого отправленного КП; форма `ФормаРедакции` (просмотр, перепечатка, «Вернуть эту редакцию»).
- Макет `КоммерческоеПредложение` (A4, логотип и печать организации, подвал реквизитов), печать Devis у КП убрана.
- Права: регистр — только Read у ролей КП; запись — из модуля документа в привилегированном режиме с флагом.

2.0.16.51 (2026-10-10):
- **Печать КП падала** («Поле объекта не обнаружено (Номер)»): макет собран скриптом `scripts/mxlxgen/kp_quotation.py`
  с индексами форматов с нуля, а в mxlx они с единицы — каждая ячейка получала формат соседа. Генератор исправлен,
  макет перегенерирован (по сравнению с прежним меняются только индексы форматов). Правило — tiny1C `tmpl-003`.
- **Удаление КП с редакциями отказывало**: каскад платформы по ведущему измерению писал пустой набор без флага.
  Документ очищает свои редакции в `ПередУдалением`; пустой набор без флага пропускается, когда редакций уже нет.
- **Язык печати**: снимок хранит сумму прописью на каждом языке, договор — без подписи; плашка редакции, условия,
  подпись договора, имя файла, даты — на языке окна печати (`ПечатныеФормы.ЯзыкПечати()`, `ЛокализацияФормата()`,
  `СуммаПрописью(…, КодЯзыка)`). Снимки формата 1 печатаются как раньше.
- `Ответственный` вошёл в состав редакции (печатается вместо пустого менеджера). Редакции, записанные 2.0.16.50,
  сравниваются в своём составе, смена ответственного сверяется с напечатанным именем — ложной новой редакции нет.
