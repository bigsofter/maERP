# 2.0.16.111 — колонки режима «Товары» на «Поступлениях» рабочего места закупок

Клиент — Drissotex. Замечания владельца 2026-10-28 по 2.0.16.108: характеристика — по функциональной опции; единица
из номенклатуры; цена и сумма — по настройке пользователя; взаимодействие колонок — как в рабочем месте производства
(склад определяет поступление или приходный ордер, поля просмотра заполняются по товару).

## Сделано

- Колонка «Склад» (`ТоварыПоступлений.Склад`): новая строка — склад поступлений пользователя (затем склад по умолчанию
  документа); смена склада — документ «Новое поступление» / «Новый приходный ордер», выбор документа — только
  документы этого склада; записанная строка показывает склад документа, только для просмотра. Механизм:
  `АРМПроизводство.НовыйДокументЗакупки` ставит склад строки в поступление, `ОрдерВместоДокумента` выбирает ордер.
- По товару, поставщику, характеристике, документу и складу новой строки — единица из карточки и «заказ № …» тем же
  путём, что запись (`ПутьСтрокиТоваров`).
- «Характеристика» (все таблицы формы) — по опции `ИспользоватьХарактеристикиНоменклатуры`; «Цена», «Сумма» строк —
  `АРМПроизводство.ПоказыватьСуммы` (настройка пользователя «Видеть суммы», иначе по роли).
