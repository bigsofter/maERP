# Отчёт: Закупки, поставщики, НСИ (номенклатура, контрагенты, пользователи), прочие справочники и перечисления

Источники: `diff-index.txt`, каталог `diffs/` (предок 18.08 → drissotex), сверка с нашим текущим
состоянием `build/xml-current` и `src/cf/src`.

## 1. Краткое резюме

В области закупок/НСИ drissotex добавил немного, но точечно:

- **Печать описания номенклатуры**: реквизит `Номенклатура.ВыводитьНаПечатьОписание` + параметр `ЭтоПечать`
  в `ОбщегоНазначенияКлиентСервер.ПредставлениеНоменклатуры`, вызовы из печати ПТУ и налоговой накладной.
- **Список номенклатуры**: вместо колонки «Продано» (обороты `Продажи` за 12 мес. по складу пользователя) —
  колонки «Цена закупки» (последняя цена из `ЦеныНоменклатурыПоставщиков`) и «Розничная цена».
- **Контрагенты**: флаг `Субподрядчик` (нужен переработке), представление карточки по марокканским
  реквизитам (IF / Patente / RC / CNSS / ICE), снятие обязательности `Категория`/`ТипЦены`/`РодДеятельности`/`Ответственный`.
- **Налоговая накладная покупки (НалоговаяНакладнаяПокупка)** — смена учётной модели: проведение по
  `ТоварыВНаличии` (когда склад «налоговый») и `ВзаиморасчётыСПоcтавщикамиНалоговый` вместо
  `ВзаиморасчётыСПоставщиками`; ввод на основании ПТУ с переносом входящего номера/даты.
- **Печать «Заказ поставщику»**: новый макет (935 строк) с итогом, «подвалом» с реквизитами организации,
  прижатым к низу страницы.
- **Мелочь**: выбор партии по остаткам (форма `ПоступлениеТоваровУслуг.ВыборПартииПоОстаткам` +
  модуль `ПартииИРазмещениеКлиент`, используется только `ВыпускПродукции`), фикс регистра цен для минимальной
  цены, колонка «Бренд» в установке цен, поиск по наименованию в `ЗагрузкаИзExcel`, исправление запроса
  `РеестрНалоговыхНакладныхЗакупка`, отчёт `РасчетыСПоставщиками` по всем контрагентам.
- Производственные основы в этой области (`ТипыНоменклатуры.Продукция/Полуфабрикат/Сырье`,
  ТЧ `ТехнологическаяКарта`, ФО `Производство`, страница «Техкарта») **у нас уже есть**, но созданы
  независимо — **uuid не совпадают** с drissotex (см. п. 2.A5).
- Всё, что «исчезло» в drissotex относительно предка (ЛКП: `ОтражатьвЛКП`, `Картинка`, `ЛичныйКабинетПартнера`,
  `Пользователь/Логин/Пароль`, `Пользователи.Внешний/Контрагент`, `SessionParameters.Контрагент`,
  константы кластера в подсистеме) — наши объекты, не их удаления.
