# Волна 9: проверка переноса Rayssouni (часть 1) на данных (`build/ib`)

Обновление `build/ib` из EDT headless недоступно (1cedtcli без JVM) —
проверку выполняет владелец.

## 1. Обновить конфигурацию

EDT → Refresh, синтаксический контроль: `ОбщегоНазначения`,
`ОбщегоНазначенияВызовСервера(ПовтИсп)`, `РаботаСДокументами(-ВызовСервера,
-Клиент, -КлиентСервер)`, `КомандыТабличныхЧастейВызовСервера/Клиент`,
`ПодпискиНаСобытия`, менеджеры `ЦеныЗакупки`/`ЦеныПродажи`/
`РазрешениеНаРедактированиеДокументов`/`ЦеныНоменклатуры`/
`ПравилаЦенообразования`, модули форм РТУ, заказа покупателя, накладной,
возвратов, оприходования, `ВидыЦен/ФормаЭлемента`, `Номенклатура/ФормаПодбора`.
Реструктуризация при обновлении БД:

- реквизиты `СуммаНДС`/`СуммаБезНДС` в шапках 10 документов,
  `ЦенаВключаетНДС` в 6 документах, `НоменклатураСтрока` и `Партия` в ТЧ,
  `СтавкаНДС`/`СуммаНДС`/`СуммаСНДС` в ТЧ оприходования;
- `Контрагенты.КодДляПоиска`; предопределённый `ТелефонФикс` (создаётся при
  записи любого вида реквизитов или обновлении);
- реквизиты `ВидыЦен` (динамический расчёт);
- новые регистры `ЦеныЗакупки`, `ЦеныПродажи`,
  `РазрешениеНаРедактированиеДокументов`; константа и ФО
  `ВыборПартииПриПродаже`; отчёт `ИсторияТовара`; подписка
  `ПослеЗаписиСнятиеРазрешенияНаРедактирование`.

## 2. Заполнение данных (обязательно, один раз)

**`ЦенаВключаетНДС` = Истина** для всех существующих документов продаж
(`ЗаказПокупателя`, `РеализацияТоваровУслуг`, `НалоговаяНакладная`,
`ВозвратОтПокупателя`, `ВозвратОтПокупателяНалоговый`,
`ОприходованиеТоваров`): после реструктуризации флаг у истории Ложь, а вся
история велась в ценах с НДС. Групповое изменение реквизитов или обработка.
Без этого пересчёт строки в старом документе посчитает НДС сверху.

`ОприходованиеТоваров`: старым строкам ТЧ `СуммаСНДС` проставляется при
записи автоматически (СуммаСНДС = Сумма); групповое заполнение не нужно,
но при перепроведении без записи объекта суммы возьмутся из ТЧ как есть.

## 3. Режим «цена без НДС» (R13 по решению владельца)

1. У вида цен снять «Цена включает НДС» → новый заказ/реализация по
   контрагенту с этим типом цен получает флаг «Цена включает НДС» = Ложь;
   цена из прайса подставляется без пересчёта (цена вида и есть без НДС),
   НДС начисляется сверху: `СуммаСНДС = Сумма + СуммаНДС`.
2. В том же документе скидка: процент считается от суммы с НДС, ручная
   сумма скидки не затирается пересчётом, `СуммаНДС` пересчитывается и при
   вводе суммы вручную.
3. Смена вида цен в шапке РТУ/накладной меняет флаг и пересчитывает строки;
   переключение флажка вручную пересчитывает строки без смены цен.
4. Прайс «с НДС» в документ «без НДС»: цена уменьшается на НДС по ставке
   номенклатуры; обратно — увеличивается.
5. Шапки: `Сумма` (с НДС), `СуммаНДС`, `СуммаБезНДС` во всех 10 документах
   заполняются при записи (в т.ч. программной); колонки в списках.

## 4. Ценообразование (R5–R7)

1. Вид цен с «Динамический расчёт» (основа — себестоимость или последний
   приход, наценка % или сумма, точность): подстановка цены в заказ/РТУ
   считает цену от базы, прайс для такого вида не используется. База с НДС
   приводится к режиму НДС вида цен до наценки.
2. `ЦеныПродажи`: запись «покупатель + номенклатура» перекрывает вид цен
   документа; запись с пустым покупателем - цена по умолчанию для всех.
   Из карточки контрагента и номенклатуры регистры доступны по ссылкам
   «Перейти» (ведущие измерения). Аналогично `ЦеныЗакупки` для ПТУ/заказа
   поставщику.
3. «Последние цены» в заказе покупателя: колонки «Закупки/Продажа/Наценка %»
   (видны при праве «Заверение цен»); ввод наценки в строке пересчитывает
   цену от последней закупочной. То же в РТУ.
4. Перезаполнение цен ТЧ - один пакет запросов (без запроса на строку).

## 5. Сервис в формах (R1, R2, R8, R10)

1. В 15 товарных документах на командной панели ТЧ: подменю «Товар»
   (Карточка товара, История товара) и «Подбор товара» (недоступен в
   только-просмотре). Подбор: двойной клик - ввод количества - строка
   добавляется/суммируется, форма не закрывается.
2. Отчёт «История товара»: последние 12 месяцев, отбор по товару и
   контрагенту документа; период и отборы меняются в настройках.
3. РТУ с проведённой налоговой накладной открывается только на просмотр
   («Заполнить из Excel» недоступна). Панель «Прибыль» (себестоимость,
   выручка без НДС, прибыль, наценка) в подвале РТУ и накладной — по праву
   «Заверение цен». «Срок оплаты» в шапке накладной.
4. Разрешение на редактирование: казначей создаёт запись (документ +
   пользователь; кто разрешил и дата подставляются), пользователь
   редактирует документ в закрытом периоде один раз, после записи
   разрешение гаснет (`Разрешено = Ложь`, дата использования). Константа
   `АвтозакрытиеПериода` (дней) закрывает складские/торговые документы
   без ручной даты запрета; заказы и кассовые/банковские не закрываются.
5. Заказ покупателя вводится на основании реализации (контрагент, цены,
   состав, флаг НДС); заказ поставщику - на основании заказа покупателя
   (основной поставщик, если один на все строки, цены - последний прайс).

## 6. Печать (R14)

1. РТУ: «Отгрузка товара (A4, без НДС)» - цены/суммы строк без НДС, итоги
   TOTAL HT / TOTAL TVA / TOTAL TTC; «(A4, без цен)» - без цен и итогов.
2. Заказ покупателя: «Накладная проформа» (HT-итоги), «КП (A4, без НДС)»,
   «КП (A4, без цен)»; «Bon de commande» - существующая команда «Заказ
   клиента». Печать в валюте договора, 4 языка.
3. `НоменклатураСтрока` (колонка «Наименование для печати», включается в
   настройке формы): заполнена - подставляется в печать Devis/BL/Facture
   и заказа вместо наименования.

## 7. Отчёты (R17) и партии (R23)

1. «Ведомость по товарам на складах»: поля «Сумма без НДС» (остатки/обороты)
   и «Себестоимость без НДС» — после перепроведения истории (волна 8).
2. «Ведомость по продажам»: «Чистая прибыль» = выручка без НДС − полная
   себестоимость (входной НДС себестоимости пока не выделяется - TECHDEBT).
3. Константа «Выбор партии при продаже» (Параметры): в РТУ появляется
   колонка «Партия» с подбором по остаткам; списание идёт по выбранной
   партии, контроль «Недостаточно по партии».
