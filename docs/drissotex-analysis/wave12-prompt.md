# Волна 12: производственный контур (по обновлению drissotex от 2026-08-25)

Основание: `update-2026-08-25-production.md`. Решения владельца 2026-08-25:

1. Статусы — интеграция в наш механизм (СтатусыЗаказовПокупателя +
   ИсторияЗаказовПокупателейПоСтатусам), объекты drissotex не переносятся.
2. Реструктуризации разрешены обе: ВыпускПродукции (ТЧГотоваяПродукция,
   колонка ГотоваяПродукция в ТЧТовары, чистка шапки) и регистр
   ТоварыВПереработке (измерение ЗаказПокупателя).
3. Оценка ГП от субподрядчика — наша схема (себестоимость списанного сырья);
   дополнительно дать возможность указать стоимость услуги переработчика,
   она капитализируется в себестоимость ГП.
4. Ввод ОтгрузкаТовара на основании заказа НЕ убирать.
5. Повторные РТУ на основании одного заказа разрешить — частичные отгрузки
   (ослабить МожноСоздатьДокументНаОсновании для этой пары).

## Состав работ

- **А. Статусы**: +3 значения перечисления (ВПроизводстве,
  ПереданСубподрядчику, ПолученОтСубподрядчика); производственные документы
  пишут свой статус в ИсторияЗаказовПокупателейПоСтатусам при проведении;
  разовое заполнение по проведённым документам шагом
  ОбновлениеДанныхВызовСервера.
- **Б. АРМ производства**: ФормаСпискаПроизводство у ЗаказПокупателя
  (статус из среза последних), товары заказа, связанные документы; врезка в
  начальную страницу для Администратора и ОператораПроизводства; сортировка
  связанных документов по дате в форме отчёта СвязанныеДокументы.
- **В. Мультивыпуск ВыпускПродукции**: ТЧГотоваяПродукция (uuid drissotex),
  ГотоваяПродукция в ТЧТовары, шапка без Количество/КоличествоУпаковок,
  запросная техкарта, разнесение себестоимости и НДС по позициям ГП,
  переключатель НесколькоСтрокГП, перенос данных шапки шагом
  ОбновлениеДанныхВызовСервера, починка списковой формы.
- **Г. Скрытие сумм**: РаботаСДокументами.ОграничитьВидимостьРеквизитовПоТипу
  (определяемые типы Сумма/СуммаНеотрицательная) + вызовы в 10 формах
  документов для роли ОператорПроизводства.
- **Д. Роль ОператорПроизводства**: полные права на производственные
  документы и переработку, Read на окружение, без денег и цен; без прав на
  выпиленное (ОбменССайтом, НДСПродажи); видимость раздела Производство в
  CommandInterface.cmi.
- **Е. Разрез заказа в переработке**: измерение ЗаказПокупателя в
  ТоварыВПереработке, заполнение из Основание, вывод в отчёт.
- **Ж. Услуга переработчика**: стоимость услуги в ПоступлениеИзПереработки,
  капитализация в себестоимость ГП, взаиморасчёты с переработчиком.
- **З. Частичные отгрузки**: повторный ввод РТУ на основании заказа.

Правила — как в прошлых волнах: коммиты по блокам, lint до чистоты
относительно базы, без Co-Authored-By, отчёт по часам xlsx в ~/Downloads,
пуш после завершения, о Refresh/проверке в EDT сообщить владельцу.
