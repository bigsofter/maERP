## Источники

- XML drissotex: `build/drissotex/` (распаковать `build/drissotex.zip`, если
  нет). Нормализованные диффы «предок → drissotex»: `build/drissotex-diffs/`
  (`путь__с__подчёркиваниями.diff` / `.new`, индекс `INDEX.txt`). Наша
  XML-выгрузка для сверки формата: `build/xml-current/`. Правим **только
  `src/cf`**. Кириллические пути могут быть в NFD — искать через python с
  `unicodedata.normalize('NFC', …)`.
- Макеты drissotex лежат в формате конфигуратора (`Template.xml` внутри
  `Templates/Имя/Ext/`). У нас в EDT макеты табличных документов — `.mxl`
  (бинарь) либо XML; посмотри, как хранится `DevisBL` у нас, и переноси в
  том же формате. Если нужен бинарный `.mxl` — собрать его headless:
  `bash -c 'source scripts/env.sh; …'` (1cv8 DESIGNER, `/DumpConfigToFiles`
  с `-Format Hierarchical` / `/LoadConfigFromFiles`) или попросить владельца
  сделать это в EDT; в отчёте явно указать, какой путь выбран.
- Тестовая база `build/ib` — данные drissotex + конфигурация maERP;
  администратор `tinycio-1c`, пароль спросить у владельца.

### 4.0. `ВыпускПродукции` как приходный документ партии (решение принято)

Файлы: `DefinedTypes/ПриходныйДокументПартии/ПриходныйДокументПартии.mdo`,
`AccumulationRegisters/ТоварыВНаличии/ManagerModule.bsl`,
`Documents/ВыпускПродукции/ObjectModule.bsl`.

- Добавить `DocumentRef.ВыпускПродукции` в состав определяемого типа
  (у drissotex ещё `ПоступлениеИзПереработки` — **не брать**, это волна 7).
  Это меняет тип измерения `Партия` в `ТоварыВНаличии`, `Продажи`,
  `ДополнительныеРасходы` — реструктуризация при обновлении базы;
  в отчёте предупредить, что на `build/ib` и у клиентов нужно окно.
- Проверить `СформироватьОприходованиеПоВыпускуПродукции`: партия
  готовой продукции = `ДокОбъект.Ссылка`, дата партии = дата документа —
  теперь значение сохраняется. Убедиться, что `СписатьНоменклатуру` при
  последующей продаже продукции находит партию по `ВыпускПродукции` (форма
  `ТоварыВНаличии.ВыборПартииПоОстаткам` показывает её; `Партия.Контрагент`
  для выпуска пуст — допустимо, см. TECHDEBT).
- Убрать из `docs/TECHDEBT.md` пункт «ВыпускПродукции как партия готовой
  продукции», в `docs/MERGE-DRISSOTEX.md` отметить п. 4 волны 3 выполненным.
