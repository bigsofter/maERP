# Промпт: волна 1 переноса из drissotex

Ты работаешь в репозитории maERP (`~/Dev/maERP`): тиражная конфигурация
1С:Предприятие 8.5.1, исходники — EDT-проект `src/cf` (`.mdo`, `.form`,
`.bsl`, `.dcs`). Сначала прочитай `CLAUDE.md`, `docs/MERGE-DRISSOTEX.md`
(план переноса), `docs/rules-1c/README.md`; детальные отчёты по областям —
`docs/drissotex-analysis/*.md`.

## Задача

Выполнить **Волну 1** плана `docs/MERGE-DRISSOTEX.md` — 17 независимых
багфиксов и мелочей из drissotex (таблица «Волна 1»). Каждый пункт — найти
изменение drissotex, понять его, перенести в `src/cf`, проверить, закоммитить.

## Источники

- XML-выгрузка drissotex (формат конфигуратора): `build/drissotex/`. Если
  каталога нет — распаковать `build/drissotex.zip` в него. Структура:
  `Класс/Объект.xml`, `Класс/Объект/Ext/ObjectModule.bsl` (`ManagerModule.bsl`),
  `Класс/Объект/Forms/Имя/Ext/Form.xml` + `Form/Module.bsl`,
  `Класс/Объект/Templates/Имя/Ext/Template.xml`.
- Нормализованные unified-диффы «предок (18.08) → drissotex» с убранным
  шумом переводов: `build/drissotex-diffs/` — имя файла = путь с `/`→`__`
  плюс `.diff`; новые файлы — `.new`. Индекс с размером, видом и категорией
  (`theirs-only` / `both` / `nobase`) — `build/drissotex-diffs/INDEX.txt`.
- Наша XML-выгрузка для сверки формата XML↔EDT: `build/xml-current/`.
  **Правим только `src/cf`.**
- Пути с кириллицей могут быть в NFD — искать через python с
  `unicodedata.normalize('NFC', …)`, а не через `ls | grep`.

## Правила

- В волне 1 новых объектов метаданных нет: только реквизиты, свойства,
  синонимы, модули, схемы СКД существующих объектов. Префикс в именах не
  используется.
- Реквизиты и объекты, которые берутся из drissotex, создаём с их uuid
  (`uuid="…"` из XML drissotex); существующие наши объекты не
  перенумеровывать — их uuid уже выровнены с drissotex.
- Код переносить **хунками по смыслу, не файлами**: модули drissotex —
  старое состояние, они содержат удалённое нами на этапе 1 (коммит
  bddd4f5) и не содержат наших правок.
- Пользовательские строки — `НСтр` на четыре языка `ru/fr/en/es` (fr есть
  в drissotex, en/es перевести).
- Соблюдать `CLAUDE.md` и `docs/rules-1c/`: их запросы в циклах, обращения
  по ссылке, магические числа при переносе исправлять, а не копировать.
  Директивы компиляции явно.
- Обработчики событий форм в EDT привязываются в `Form.form`
  (`<handlers>` у формы, `<events>` у элементов) — процедура в модуле сама
  не вызывается.
- После правки модулей — `scripts/lint.sh`; новых замечаний BSL LS быть не
  должно. Синтаксический контроль и проверку метаданных делает EDT на
  стороне владельца — в отчёте перечислить, что ему проверить.
- Git: ветка `develop`; один коммит — один пункт (или логическая пара,
  например 1.3 + 1.9); сообщения на русском в стиле `git log`. `build/` и
  `DT-INF` не трогать.
- Не делать ничего из других волн и ничего из раздела «Не переносим» плана
  (в т. ч. «Их откаты»), даже если оно лежит в том же диффе.
