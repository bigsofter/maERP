# Реестр сценариев обработки `ТестыДокументов` (уровень 3)

Таблица всех сценариев обработки `ТестыДокументов`: что создаёт каждый сценарий и что он сверяет.
Вынесена дословно из раздела «Тесты документов (уровень 3)» файла [`docs/TESTING.md`](../TESTING.md) —
запуск, формат отчёта, устройство сценария и правило «новый документооборот — новый сценарий» описаны там.

Строки длинные (до нескольких тысяч знаков), файл целиком не читать. Искать строку по имени сценария:
`grep -n '<имя сценария>' docs/testing/doc-scenarios.md`. Строк в таблице — 172; в части строк через
запятую названо несколько сценариев.
