## Уроки сборки 3 (учесть сразу)

- Codex — по квоте: обязательные прогоны первыми (план этой сборки, затем код), второстепенные — после; лимит
  проверять дешёвым вызовом до плана. Если Codex в лимите — `architecture-critic` до кода, Codex — как только вернётся,
  и в отчёте прямо сказать, что порядок нарушен.
- Стадия заказа «В производстве» не покрывает заказы из свободного склада («ИзОстатка» пишет только автовыпуск) —
  факты о стадиях сверять с `ПроизводственныеЗаказы.СтадияПоПоказателям`, а не с текстом плана.
- Модуль формы: локальные имена не совпадают со свойствами формы (`Параметры`, `Заголовок`, `Окно` — tiny1C bsl-014);
  смок этого не ловит.
- Смок вызывает только `ПриСозданииНаСервере`: формирование отчётов проверять тестом через `ДанныеОтчета` и
  компоновку, как `ПростоиСтанков`.
- Снимок окна 1С при включённом Stage Manager: окно разворачивает только щелчок владельца, снимать сразу после.

## Состав сборки 4

1. **Детальный раздел плана и вопросы владельцу до кода** одним блоком (что в «Деньгах»: выручка без НДС или с ним,
   стоимость часа станка в себестоимости; выработка — по операторам из требования или станка).
2. Отчёты: «Загрузка станков» (фонд, план и факт работы, ТО и ремонты, «нет заказа», % загрузки), «Деньги по станкам»
   (выручка по ценам заказа, себестоимость материалов, стоимость часов, маржа на час и на кг), «Выработка» (кг и часы
   по станкам, продукции и операторам, отклонение от нормы), «Материалы на станках» (НЗП по заказам на дату).
3. Одна функция категорий времени в `ЗагрузкаСтанков` для всех отчётов; меню «Производство → Отчёты».
