## Уроки прошлых сборок (учесть сразу)

- Фаза 3: псевдоним таблицы в запросе не совпадает с полем временной таблицы (`Номенклатура` → «поле
  неоднозначно», query-003); разыменование через точку в запросах адаптеров — явными соединениями, составное поле
  документа отгрузки — пакетным `ЗначенияРеквизитовОбъектов` по видам; локальная переменная не называется
  `Документы` (bsl-011).
- Фаза 3: удаление макета из метаданных прячет сохранённую правку клиента из списка макетов — макеты удаляются только
  в фазе 7.
- Фаза 3: дифф со сгенерированным `Template.mxlx` выводит промпт Codex за 1 МБ — ревью-обёртки запускать с
  `AI_DIFF_EXCLUDE='*.mxlx'` (генератор `branded.py` в диффе остаётся).
- Фаза 3: во время `ib-sync.sh` на той же базе не запускать внешние обработки и предпросмотр — загрузка XML падает с
  rc=1 без текста; «Экспорт EDT не удался (rc=204)» — гонка выгрузки, повторить; `src/cf` не трогать во время экспорта.
- Фаза 3: BSL LS на новом коде — `NestedFunctionInParameters` (вызов в параметрах `Вставить`/`Добавить` — через
  переменную), `DuplicateStringLiteral`, `MissingParameterDescription` у процедур тестов, `NonExportMethodsInApiRegion`.
- Фаза 3: у копий баз и у 2MZL пустые параметры прописи валют — пропись по умолчанию есть для MAD/EUR/USD/RUB;
  отправленные снимки КП хранят сумму прописью, как была записана.
- Номер документа фиксированной длины дополнен пробелами (tiny1C bsl-026): номера сравнивать через `СокрЛП`;
  номера разных видов документов могут совпасть — проверки «номер не напечатан» только при различии.
- Адаптер выбирается **по типу ссылки**, а не по менеджеру печати: проверки доступа и опций — в самом адаптере.
- Роль `ОператорПроизводства` не видит цены и суммы — печатные формы с ценами для неё — вопрос `ai-security`.
- Печать, которая пишет данные, — только в транзакции; смок формирует формы в транзакции с откатом.
- `ib-sync.sh`, `doctests.sh`, `smoke.sh`, `cf-dump.sh` — через `bash -c`; rc=141 без строк в логе — повтор; итог
  тестов — строка `ИТОГ;Сценариев=…`; отчёты 1С — CRLF и BOM (`tr -d '\r'`).
- Внешние обработки headless — `/DisableUnsafeActionProtection` с маской своей базы (workflow-015).
- `ai-review --verify` смотрит дельту: закрытое прошлым кругом может прийти «partially_fixed» — сверять с файлом.
