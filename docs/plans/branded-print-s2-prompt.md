## Шаг 2. Код (раздел 3.3 плана — дословно, без упрощений)

- `Документы.КоммерческоеПредложение.КПВводятсяВручную()` — константа в привилегированном режиме.
- `Документы.КоммерческоеПредложение.СинхронизироватьСРеализациями(МассивРеализаций)` — пакетный протокол: блокировка
  реализаций → повторное чтение активных авто-КП (включая помеченные) → создание / обновление только при изменении /
  разбор дублей с записью в журнал → запись с флагом `СинхронизацияКП`; привилегированный режим на весь протокол;
  номер и дата — из реализации; пометка удаления — зеркально; возвращает соответствие реализация → КП.
- КП `ПередЗаписью`: отказ ручной записи при выключенной опции (кроме служебных флагов и обмена); сброс
  `Автосинхронизация` при записи не синхронизацией, статусе не «Черновик», появлении редакции; запрет ручной
  установки флага; проверка уникальности номера ручного КП (если снят `checkUnique`). `ПриКопировании` — флаг Ложь.
- Реализация `ПриЗаписи` (не при `ОбменДанными.Загрузка`, только при выключенной опции) — протокол для одной
  реализации в её транзакции. Ошибка КП — текст называет КП.
- Реализация `ДобавитьКомандыПечати` — команда `КоммерческоеПредложение` («Devis») только при выключенной опции;
  `Печать` — протокол по всему массиву, затем `Документы.КоммерческоеПредложение.Печать` по КП; область печати и
  имя файла — по реализации. Данные — только из КП.
- `СмокТест.ПроверитьПечатнуюФорму` — каждая печатная форма в транзакции с откатом (смок не меняет базу).

## Уроки прошлых сборок (учесть сразу)

- Функциональная опция в одном серверном вызове кэшируется — читать константу (bsl-023); у опции
  `privilegedGetMode = true` — константу читать в привилегированном режиме.
- Отказ записи посреди сценария портит транзакцию — настоящий отказ только последним шагом; проверки «без записи» —
  функциями модуля.
- Циклы в shell — через `bash -c`: zsh не разбивает `$args` на слова (фаза 1: код языка «ru 00000000005»).
- `scripts/*.sh` — через `bash`; логин базы — `SMOKE_USER/SMOKE_PWD` из `.claude/settings.local.json`; `src/cf` не
  трогать, пока идёт `ib-sync.sh`; прогоны на одной копии базы — не параллельно.
- Имена методов без «ё» (BSL LS YoLetterUsage); `ПриДобавленииОбработчиковОбновления` у предела длины — новые
  обработчики через `ДобавитьОбработчикиРазделов`.
- `ai-review --verify` смотрит дельту: закрытое прошлым кругом может пометить «not_fixed» — сверить с файлом.
