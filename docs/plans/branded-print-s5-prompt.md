## Уроки прошлых сборок (учесть сразу)

- Фаза 4: **право на команду без права на её данные — отказ при печати**. Замена команды даётся роли, только если роль
  читает всё, что читает адаптер (ПКО, банковские чеки, регистры расчётов…); сверять по `Rights.rights` и в тесте
  `ПравоДоступа("Чтение", Объект, Роль)`. Ревью плана фазы 4 трижды возвращало именно это.
- Фаза 4: регистр `ВзаиморасчётыСПокупателями` хранит суммы в **основной валюте** — подписывать их валютой документа
  нельзя (ревью кода, P2); у сверки — то же для сальдо и оборотов.
- Фаза 4: многострочный литерал `НСтр` переносит строку в текст — постоянные тексты вида выводить через
  `ТекстОднойСтрокой`.
- Фаза 4: синонимы команд бывают машинным переводом («Avoir» → «Have»/«Tener»); проверять синонимы заменяемых команд и
  кнопок на четырёх языках. В РМК (`VentesEnDetail`) «Have»/«Tener» остались — TECHDEBT.
- Фаза 4: переменная цикла не называется ключевым словом (`Возврат`) — BSL LS даёт ParseError; документ теста —
  с заполненной хозяйственной операцией, иначе проверка заполнения.
- Фаза 4: `ПравоДоступа(Право, Объект, Роль)` с третьим параметром проверяет роль, а не текущего пользователя; печать
  от пользователя роли раннер не воспроизводит — сказать в отчёте.
- Фаза 3: псевдоним таблицы в запросе не совпадает с полем временной таблицы (query-003); разыменование через точку в
  запросах адаптеров — явными соединениями; имя документа в тексте запроса — подстановкой `"Документ." + Имя`, а не
  `Документ.#Имя` (BSL LS QueryToMissingMetadata).
- Фаза 3: удаление макета из метаданных прячет сохранённую правку клиента — макеты удаляются только в фазе 7.
- Фаза 3: ревью-обёртки — с `AI_DIFF_EXCLUDE='*.mxlx'` (промпт Codex ≤ 1 МБ).
- `ib-sync.sh`: «Экспорт EDT не удался (rc=204)» / «feature with code "type"» — гонка выгрузки, повторить; во время
  экспорта `src/cf` не трогать; на той же базе не запускать предпросмотр и тесты одновременно.
- Номер документа фиксированной длины дополнен пробелами (bsl-026): сравнивать через `СокрЛП`.
- Адаптер выбирается **по типу ссылки**, а не по менеджеру печати: проверки доступа и опций — в адаптере или на общем
  входе `ФирменнаяПечать.Напечатать`.
- `ib-sync.sh`, `doctests.sh`, `smoke.sh`, `cf-dump.sh` — через `bash -c`; rc=141 без строк в логе — повтор; итог
  тестов — строка `ИТОГ;Сценариев=…`; отчёты 1С — CRLF и BOM (`tr -d '\r'`).
- `sort`/`uniq` по кириллице — только с `LC_ALL=C` (иначе разные строки схлопываются).
