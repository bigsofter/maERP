# Печать инвентаризации: инвентаризационная опись и сличительная ведомость

Тикет 2606300 (TinyCIO, 2026-11-16): «Документ Инвентаризация. Добавить печатную форму с количеством и с/с (по
балансу, фактически, разница)». Решения владельца 2026-11-20: себестоимость — средняя по всем складам; опись печатает
все строки; отдельная форма «Сличительная ведомость» — только строки с расхождением; название «Инвентаризационная
опись» / «Inventaire valorisé». Сборка 2.0.17.48.

## Что есть

- «Инвентаризация» — `Документ.ПересчётТоваров` (fr «Inventaire des marchandises»): не проводится, строки `ТЧТовары` —
  Номенклатура, Характеристика, Упаковка, Серия, КоличествоУпаковок/Количество (учёт, заполняет
  `ПересчётТоваров.ЗаполнитьУчетноеКоличество` по остаткам места хранения на дату), КоличествоУпаковокФакт/КоличествоФакт.
  Шапка: Организация, МестоХранения, Ответственный, Исполнитель, ТоварнаяГруппа, Статус, Комментарий. Печати нет.
- Себестоимость за единицу. `ТоварыВНаличии.ПолучитьСреднююЦенуПоОстаткам` **не подходит** (ревью плана, круг 1): сумма
  остатков с НДС, цена округлена до 2 знаков до умножения, неподтверждённые партии определяются по текущему состоянию
  базы. Образец без НДС — `Отчеты.МатериалыНаСтанках` (`СуммаОстаток - СуммаНДСОстаток` по `ТоварыВНаличии` и
  `ДополнительныеРасходы`).
- Механизм печати: `ДобавитьКомандыПечати` и `Печать` в модуле менеджера, объект в `ПечатныеФормы.ОбъектыСКомандамиПечати`,
  команда объекта в группе `CommandGroup.Печать` (`ПечатныеФормыКлиент.ВыполнитьКомандуПечати`), макет через
  `ПечатныеФормы.МакетПечатнойФормы`, флаг `БезЦен` и `ПечатныеФормы.ПечататьБезЦен`. Образец как у
  `Документ.СписаниеТоваров.АктСписанияТоваров`.

## Что делаю

1. **Макет** `Документ.ПересчётТоваров.ИнвентаризационнаяОпись` — генератор `scripts/mxlxgen/inventory.py` (формат mxlx
   по образцу `branded.py`, руками не правится). Альбомная ориентация. Области: `Заголовок` (ТекстЗаголовка),
   `Реквизиты` (Организация, МестоХранения, Дата), `ШапкаТаблицы` (две строки: группы «По учёту / Фактически / Разница»
   и подписи колонок), `Строка`, `Итого`, `ШапкаТаблицыБезЦен`/`СтрокаБезЦен`/`ИтогоБезЦен` (только количества),
   `Подписи` (Ответственный, Исполнитель). Колонки: №, Артикул, Товар, Ед., С/с за ед., Учёт кол-во, Учёт сумма, Факт
   кол-во, Факт сумма, Разница кол-во, Разница сумма. Заголовок — параметр: одна раскладка на обе формы.
2. **Модуль менеджера** `ПересчётТоваров`: `ДобавитьКомандыПечати` — две команды (`ИнвентаризационнаяОпись`,
   `СличительнаяВедомость`, обе `БезЦен = Истина` — печатаются и без цен, только количествами); `Печать` —
   `ПечатьОписи(Док, Таб, ТолькоРасхождения, БезСумм)`; данные — `ДанныеОписи(Док)` экспортной функцией (её зовёт тест):
   строки ТЧТовары в порядке номера строки, количество в базовых единицах (`Количество`, `КоличествоФакт`), единица
   хранения номенклатуры. Себестоимость — своя функция `ДанныеЦен(Номенклатура, Граница)`: остатки `ТоварыВНаличии` и
   `ДополнительныеРасходы` на границу документа (`РаботаСДокументамиВызовСервера.ПолучитьГраницуДокумента`) по всем
   складам, по номенклатуре и характеристике, `Сумма − СуммаНДС` и количество без округления; **все партии**, без
   исключения неподтверждённых (их признак — текущее состояние базы, а опись должна печататься одинаково при тех же
   движениях до даты пересчёта). Суммы строки = Окр(количество × сумма остатка / количество остатка, 2) — без
   промежуточного округления цены; цена за единицу печатается округлённой до 2 знаков только для вида. Количество
   остатка ≤ 0 — цена 0. Разница = факт − учёт (кол-во и сумма, со знаком). Сличительная ведомость — строки с
   ненулевой разницей количества; нет расхождений — строка «Расхождений нет» вместо таблицы. Итоги — суммы учёта,
   факта, разницы (количества разных единиц не складываю).
   **Право на суммы** (ревью плана, круг 1, P0): права ролей на команды не ограничивают серверное формирование
   (`ПечатныеФормы.СформироватьПечатныеФормы` их не проверяет). `БезСумм = ПечататьБезЦен(ПараметрыПечати) Или Не
   ПравоДоступа("Просмотр", <команда описи>)` — роль без права на команду (`ЛичныйКабинет`, `MobileClient`,
   `ОператорПроизводства`, вызвавшие API сервера) получает только количества.
3. **Метаданные**: макет и две команды объекта (`ПечатьИнвентаризационнаяОпись`, `ПечатьСличительнаяВедомость`) в
   `CommandGroup.Печать`, параметр `DocumentRef.ПересчётТоваров`, Multiple; `Документ.ПересчётТоваров` в
   `ОбъектыСКомандамиПечати`.
4. **Права**: `View` на обе команды — ролям с `View` документа и без `setForNewObjects`: `Кладовщик`,
   `МенеджерПоЗакупкам`, `PDV` (у `Администратор`, `Руководитель` — новые объекты по умолчанию). `ЛичныйКабинет`,
   `ОператорПроизводства` (только `Read`), `MobileClient` — без команд. Цены у пользователя без права цен скрывает
   `ПечататьБезЦен` (как у акта списания).
5. **Тест** `ПечатьИнвентаризации` (`ТестыДокументов`): пересчёт с двумя товарами на остатке (один с расхождением),
   `ДанныеОписи` — цена равна средней цене остатков, суммы и разница; печать обеих форм через
   `ПечатныеФормы.СформироватьПечатныеФормы` — непустой табличный документ, в ведомости одна строка товара.
   Смок печатает обе формы на образце (`ОбъектыСКомандамиПечати`).
6. **Версия** 2.0.17.48, «Что нового» ru/fr/en/es, хаб, «Проверка 2.0.17.48» в docs/testing/checks-history.md, TESTS.xlsx.

## Не делаю

- Себестоимость по месту хранения и по серии (решение владельца — по всем складам; функция серии не различает).
- Запись цены в документ: цена считается при печати на дату документа — повторная печать даёт то же, пока не изменились
  движения до даты документа.
- Печать из списка `ЗаданиеНаПересчет`.

## Риски

- Средняя цена на дату документа меняется, если задним числом проведены документы до даты пересчёта — опись
  расчётная, это ожидаемо (как учётное количество при перезаполнении). Неподтверждённые партии входят в цену по
  своей сумме — ревью плана, круг 1: иначе цена зависит от текущего, а не исторического состояния.
- Ревью плана, круг 1 (reject, 4 находки): НДС, округление цены, неподтверждённые партии, серверная печать — учтены выше.
- Товар без остатков ни на одном складе — цена 0, суммы 0 (строка печатается).
