## Уроки прошлых сборок (учесть сразу)

- Фазы 3–6: **удаление макета прячет сохранённую правку клиента** — ради этого макеты дожили до фазы 7; удаление
  процедур правок не прячет.
- Фаза 6: в EDT `Рисунки` табличного документа без `Найти`; одноимённые рисунки при выводе переименовываются; команда
  недоступна без права «Просмотр» владельца (PDV и заказ поставщику); Руководитель и Администратор получают права на
  новые объекты автоматически (`setForNewObjects`).
- Фаза 6: адаптер выбирается по типу ссылки — проверка вида и права на команду в самом адаптере (`ai-security`, P0);
  при удалении веток `Печать` эту проверку не потерять.
- Фаза 5: `ПравоДоступа` на команду — и на сервере; реквизит «прежней формы» сверять по `.mdo`, а не по коду; числа в
  тестах — литералами (испанская локаль).
- Фаза 4: снятие команды — блок `commands` в `.mdo`, каталог `Commands/…`, кнопки во всех формах (workflow-004/009),
  права в `Rights.rights` всех ролей, строка `titlecheck-baseline.txt`.
- Фаза 3: имя документа в тексте запроса — подстановкой; ревью-обёртки с `AI_DIFF_EXCLUDE='*.mxlx'`.
- Пробы внешней обработкой: `И`, `В` и подобные — зарезервированные слова (имя переменной, псевдоним запроса); зависшие
  процессы 1С снимать по PID, а не `pkill` по шаблону.
- `ib-sync.sh` / `doctests.sh` / `smoke.sh` — через `bash -c`; во время экспорта EDT `src/cf` не трогать; rc=134 у JVM EDT
  и rc=141 без строк — повтор; итог тестов — `ИТОГ;Сценариев=…`, отчёт перечитывать после завершения, а не старый; отчёты
  1С — CRLF и BOM (`tr -d '\r'`); на одной базе не запускать предпросмотр и тесты одновременно; сценарии демо-данных
  пропускаются сразу после полуночи — это не ошибка фазы.
- `sort`/`uniq` по кириллице — только `LC_ALL=C`.
