## Риски

1. Пропущенное вхождение имени строкой (`Константы.<Имя>`, `"Константа.<Имя>"`) линтер и `refcheck`
   не видят — ловит CheckConfig и прогон уровня 3 (иначе прогон висит без ИТОГ).
2. Правка формы — точечно по имени элемента (`workflow-009`), `git diff -w`; `<visible>true</visible>`
   у элемента уже есть.
3. CFU поставки: объект сопоставляется по uuid — переименование при обновлении клиента данные не трогает.
