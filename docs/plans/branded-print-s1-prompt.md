## Шаг 1. Скрипт предпросмотра — до переделки

`scripts/print-preview.sh <ПолноеИмяОбъекта> <ИмяМакета> [КодЯзыка] [Ссылка|последний]` — на копии базы
(`build/ib-kp`, по умолчанию; `build/ib` занята EDT): внешняя обработка (образец — `build/2mzl/build_epf.py` и
`run.sh`, их не трогать — скопировать нужное в `scripts/`) печатает форму через `ПечатныеФормы` так же, как окно
печати, пишет PDF и рендерит PNG (`pdftoppm`) в `build/print-preview/`. Учесть грабли из памяти проекта: первый
`/Execute` после обновления конфигурации может висеть на «Предупреждении безопасности» — таймаут и понятное
сообщение, не бесконечное ожидание. Сразу снять **эталон** КП (документ с плашкой редакции и без, ru/fr/en/es) —
с ним сравнивается результат шага 3.

## Шаг 2. Общий макет и модуль

- Генератор `scripts/mxlxgen/branded.py` (из `kp_quotation.py`, константа `PT = 4`): общий макет
  `CommonTemplates/ФирменныйДокумент` — области КП плюс варианты колонок и блоков из раздела 3.1 плана (в фазе 1 —
  только области; варианты, которых КП не использует, тоже генерируются и проверяются сценарием на заполнение
  параметров). `kp_quotation.py` и макет КП удаляются, когда КП переведён (шаг 3), — в этой же сборке, после полного
  поиска ссылок (tiny1C workflow-013) и refcheck.
- Общий модуль `ФирменнаяПечать` (сервер, без вызова сервера с клиента): `ВидыФорм`, `Вывести`, `Напечатать`,
  `ДобавитьКоманду`, приведение структуры старой версии (`ВерсияФормата` 1–2 → 3, раздел 3.2 плана). Экспортные
  методы — с комментарием назначения, параметров, результата. Язык — только явный `КодЯзыка`, `НСтр(..., КодЯзыка)`.
- Адаптер КП: `Документы.КоммерческоеПредложение.ДанныеФирменнойПечати(Ссылки, ВидФормы, КодЯзыка)` — пакетно; снимок
  редакции и текущее состояние — как в `ИсточникПечати` сейчас (явная версия, отправленная без правок, черновик
  следующей редакции).

## Шаг 4. Тесты

- Сценарий `ТестыДокументов` **`ФирменнаяПечать`**: каждый вид из `ВидыФорм` с адаптером КП формируется на 4 языках;

  `КоммерческоеПредложение` и `РедакцииКоммерческогоПредложения` проходят без правок своих проверок.
- `docs/TESTING.md`: строка реестра и ручная проверка «Фирменные печатные формы» (как смотреть предпросмотр);

## Уроки прошлых сборок (учесть сразу)

- Высота строки mxlx — четверти пункта (2.0.16.67), индексы форматов — с единицы (2.0.16.51): генератор проверять

- Пустая ячейка с заливкой печатается цветным прямоугольником — заливку снимать кодом, если параметр пуст
  (`Область("R…C…:R…C…").ЦветФона`), координаты — строкой адреса (MagicNumber BSL LS).
- Параметр, который метод переприсваивает, — `Знач` (bsl-025); имя встроенной функции — по образцу из конфигурации.
- Не трогать `src/cf`, пока идёт выгрузка `ib-sync.sh`; прогон на той же копии базы не запускать параллельно с
  другим прогоном — остановить по id задачи, не `pkill`.
- Скрипты `scripts/*.sh` — через `bash`, логин базы — `SMOKE_USER/SMOKE_PWD` из `.claude/settings.local.json`.
- `ai-review --verify` смотрит дельту: закрытое прошлым кругом может пометить «not_fixed» — сверить с файлом.
