# План S6: закладка «Поступления из переработки» и услуги переработчика в строках продукции

Промпт — `docs/plans/production-subcontracting-s6-prompt.md`. Сборка **2.0.15.48**. Ссылки сверены на `a93fc19`.

## Решения владельца (2026-09-22)

1. **Новая нижняя закладка** «Поступления из переработки» рядом с «Переработкой», своя таблица.
2. **Строка = строка продукции** поступления (`ТЧГотоваяПродукция`): передача-основание, продукция, характеристика,
   упаковка, количество, процент потерь. Сырьё в рабочем месте не показывается, сервер пересчитывает его
   `ЗаполнитьСырье`; правка сырья руками — в документе.
3. **Стоимость услуг переработчика хранится в строках продукции**, шапка — только сумма строк. Правка суммы в
   шапке документа распределяет её по строкам (база — решение 7). В рабочем месте — колонка при включённых суммах
   и кнопка **«+ услуга переработки»**, которая делает то же, что правка суммы в шапке.
4. **Признак «сырьё правили вручную» хранится в документе**; строку такого документа рабочее место не правит —
   «откройте документ».
5. Кнопка `ПереработкиСоздатьПоступление` остаётся (путь к документу для ручного сырья); рядом — переход на новую
   закладку с новой строкой по отмеченной передаче.
6. `Form.form` правится руками, в README генератора — отставание на три сборки; `gen7.py` не запускается.
7. База распределения услуг — **вес по технологической карте** (количество × нормы карты × (1 + потери)), то же
   правило `ТехнологическиеКарты.ВесаПродукции`, по которому проведение делит себестоимость сейчас.
8. «+ услуга переработки» — **сумма на документ** выделенной строки: распределяется по всем строкам продукции
   документа, документ перепроводится.

Решения 3, 4, 7 выводят этап за рамки промпта: новый реквизит шапки, новый реквизит табличной части,
реструктуризация таблиц документа, правка проведения (деньги) и обработчик обновления. Уровень — существенный.

## Реализация — четыре коммита

### Коммит 1. Документ: услуги в строках продукции и признак ручного сырья

**Метаданные** `ПоступлениеИзПереработки.mdo` (синонимы на ru/fr/en/es, имена без «ё»):
- реквизит шапки `СырьеИзмененоВручную` — Булево; «Сырьё изменено вручную»;
- реквизит `ТЧГотоваяПродукция.СтоимостьУслуг` — Число 15.2, неотрицательное; «Стоимость услуг».
Шапочные `СтоимостьУслуг`, `СтавкаНДСУслуг`, `СуммаНДСУслуг` остаются: их читают взаиморасчёты, демо, сценарии.

**Модуль менеджера документа** (экспортные, с описанием):
- `РаспределитьСтоимостьУслуг(Документ, Сумма)` — сумма по строкам продукции пропорционально
  `ТехнологическиеКарты.ВесаПродукции` на дату документа (с процентом потерь строки); нулевой общий вес — по количеству;
  остаток округления — на последнюю строку; шапка = сумма, НДС шапки — по ставке от суммы. Работает с объектом и с
  `ДанныеФормыСтруктура`, как `ЗаполнитьСырье`.
- `ОжидаемаяПродукция(Передача, Документ)` — ожидаемая продукция передачи за вычетом поступившей по другим проведённым
  поступлениям и остатка заказа: логика `ЗаполнитьПоПередаче` + `ВычестьПоступившуюПродукцию` +
  `ОграничитьОстаткомЗаказа` переносится сюда, объект вызывает её (одно правило на форму, заполнение и рабочее место).
  Колонки — номенклатура, характеристика, упаковка, количество упаковок, количество.
- `СинхронизироватьСтоимостьУслуг(Документ)` — строки нулевые, шапка не нулевая → `РаспределитьСтоимостьУслуг`
  (старый код, демо и загрузки, пишущие только шапку, продолжают работать); иначе шапка = сумма строк, НДС по ставке.

**Модуль объекта:** `ПередЗаписью` (не в режиме загрузки) — `СинхронизироватьСтоимостьУслуг`; `ОбработкаПроверкиЗаполнения` —
отрицательная стоимость услуг строки отклоняется. `ЗаполнитьПоПередаче` — через `ОжидаемаяПродукция`.

**Проведение** (`ТоварыВНаличии`): `РаспределитьСебестоимостьНаПродукцию` получает необязательный параметр — стоимость и НДС
услуг по строкам; у выпуска продукции не передаётся, поведение выпуска байт в байт прежнее. Поступление: себестоимость
сырья и её НДС делятся по весам, как сейчас; к строке прибавляется её `СтоимостьУслуг` и доля `СуммаНДСУслуг`
пропорционально стоимости услуг строки (остаток — на последнюю строку с услугами). Страховка: сумма строк не равна
шапке (документ не прошёл обработчик, загрузка) → прежний путь «шапка вместе с сырьём по весам».
Долг переработчику — по шапке, без изменений.

**Форма документа:**
- колонка `СтоимостьУслуг` в таблице продукции, видимость — как у сумм документа (`ОграничитьВидимостьРеквизитовПоТипу`
  для `ОператорПроизводства`); итог в подвале;
- правка строки → шапка = сумма строк; правка шапки → `РаспределитьСтоимостьУслуг`; оба пути пересчитывают НДС;
- признак: форма взводит `Объект.СырьеИзмененоВручную` там же, где сейчас взводит реквизит формы
  `СырьеПравилосьВручную` из-за правки сырья (добавление, удаление, номенклатура, упаковка, количество, серия, штрихкод);
  «Рассчитать сырьё» снимает. Реквизит формы остаётся — он про другое: «записанный документ сам не пересчитывается»
  (2.0.15.45); на чтении он по-прежнему Истина, признак документа — нет. Поле признака показывается в шапке только
  для чтения с подсказкой «рабочее место строки такого документа не правит».

**Обработчик обновления `2.0.15.48`** `ЗаполнитьУслугиИПризнакПоступленийИзПереработки` (монопольно, идемпотентно,
запись в режиме загрузки — без перепроведения, движения не меняются):
- шапка с услугами, строки нулевые → `РаспределитьСтоимостьУслуг` на дату документа;
- `СырьеИзмененоВручную = Истина` у всех существующих документов с непустым сырьём: откуда их сырьё (весь остаток до
  S5-B или ручная правка) — неизвестно, поэтому рабочее место их не правит. «Рассчитать сырьё» в документе снимает
  признак. Решение осторожное, владелец может отменить.
- повтор ничего не пишет (отбор по условиям выше).
Движения старых документов остаются прежними; при ручном перепроведении себестоимость строки может сдвинуться
на копейки округления (раньше делилась сумма «сырьё + услуги», теперь по отдельности) — в «Что нового» и в TECHDEBT.

### Коммит 2. Рабочее место, сервер: вид «Поступление из переработки»

`ВидПоступлениеИзПереработки()` = `"ПоступлениеИзПереработки"`, в `ВидыСтрокДокументов`, `ПраваРабочегоМеста`
(`МожноВводитьПоступленияИзПереработки`).

**Данные строки** — в `НовыеДанныеСтрокиДокумента` и проверку типов: `Передача` (`ДокументСсылка.ПередачаВПереработку`),
`ПроцентПотерь` (Число), `СтоимостьУслуг` (Число), `УслугиИзменены` (Булево — как `ЦенаИзменена`: без показа сумм
услуги строки не трогаются). Позиция строки — `Продукция`.

**Строки закладки** `СтрокиПоступленийПереработки(Заказ)` / ветка в `СтрокиДокументов`: строки продукции непомеченных
поступлений, чьё основание — передача этого заказа; колонки — документ, передача (представление), переработчик и склад
из шапки, продукция, характеристика, упаковка, количество, процент потерь, стоимость услуг (скрывается без сумм),
статус, признак документа за сегодня. `ТолькоПросмотр` — серия в строке, `СырьеИзмененоВручную`, основание не передача.
Проверка права чтения — документа и регистра `ТоварыВПереработке`.

**Реквизиты документа строки:** `ИменаРеквизитовДокументаСтроки` — `СырьеИзмененоВручную` только у этого документа
(урок про «безусловное имя» в комментарии там же); `ДополнитьРеквизитыДокументаСтроки` — заказ клиента берётся из
основания передачи.

**Запреты** (каждый — текст на четырёх языках):
- значения: не заполнены передача, продукция или количество; характеристика не той продукции;
- передача не проведена, помечена или относится к другому заказу;
- продукции нет в ожидаемой (`ОжидаемаяПродукция` по передаче, исключая текущий документ);
- количество строки сверх ожидаемого за вычетом других строк этого документа с той же продукцией;
- документ строки: другая передача-основание (новая строка — только в документ той же передачи); новая строка —
  только в сегодняшний; `СырьеИзмененоВручную` → `ТекстПравкаВФормеДокумента()` (в `ТекстЗапретаДокументаОбъекта` —
  на заблокированном объекте тоже).

**Новый документ** `НовоеПоступлениеИзПереработки`: `СоздатьДокумент`, `Заполнить(Передача)` для шапки, затем
`ТЧГотоваяПродукция` и `ТЧТовары` очищаются; дата — текущая. **Применение строки** `ПрименитьДанныеСтрокиПоступленияПереработки`:
продукция, характеристика, упаковка (смена позиции — единица номенклатуры, серия очищается), количество, процент потерь
(новая строка или смена продукции — из карты, иначе из строки рабочего места); услуги строки — только при
`УслугиИзменены` и показе сумм; затем `ЗаполнитьСырье(ДокОбъект, Передача)`. Отказ проведения нового документа →
черновик с причиной (общий путь `ЗаписатьДокументСтроки`).

**Блокировки при правке и удалении у записанного документа** (`ЕстьЗависимыеДокументы` — да): транзакция по образцу
`ЗаписатьСтрокуДокумента:955-968` — блокировка в порядке проведения (`ЗаполнитьБлокировкуПроведения` документа:
`ТоварыВНаличии` по продукции и складу, затем `ТоварыВПереработке` по переработчику; продукция записываемой строки
добавляется в набор), затем повтор проверки ожидаемого количества, пересчёт сырья, запись с проведением. Новый документ
— та же блокировка и проверка внутри транзакции проведения (гонка двух строк сверх ожидаемого). Ошибка проверки —
пустая фиксация, как у зависимых документов.

**Удаление:** общий путь; документ без строк помечается на удаление; после удаления строк у оставшихся — пересчёт сырья и
перепроведение. Услуги удалённой строки **переходят на оставшиеся** (`РаспределитьСтоимостьУслуг` на прежнюю сумму
шапки): сумма шапки — счёт переработчика, она не должна тихо уменьшаться от удаления строки.

**Выбор значений:**
- `ПередачиЗаказаДляВыбора(Заказ)` — проведённые непомеченные передачи заказа с остатком ожидаемой продукции;
- `ПродукцияПередачиДляВыбора(Передача, Документ)` — ожидаемая продукция с количеством по умолчанию = остаток;
- `ДокументыСтрокиДляВыбора` — сегодняшние непомеченные поступления **той же передачи** без признака ручного сырья.

**«+ услуга переработки»** `УстановитьУслугиПоступления(Документ, ВерсияДанных, Сумма, Заказ)`: права, заказ, запреты
документа, версия, объектная блокировка, `РаспределитьСтоимостьУслуг`, запись в прежнем режиме (проведённый —
перепроведение). Ставка НДС — из документа.

После записи строки или услуг — `СтрокиДокумента` документа и пересчитанные строки «Переработки» (колонка «Поступления»)
и продукции заказа («Выпущено», стадия), как после записи передачи.

### Коммит 3. Рабочее место, форма: закладка, кнопки, переход

### Коммит 4. Тесты, документация, версия

**`АРМПереработка`** (расширение, один отказ проведения — последним шагом):
1. новая строка по проведённой передаче → проведённый документ, основание — передача, продукция и процент потерь из
   строки, сырьё посчитано сервером, «Выпущено» и стадия заказа;
2. **движения строки = движения документа**: второе поступление той же передачи, собранное через `Заполнить` + ту же
   продукцию на копии данных, — сверка `ТоварыВПереработке` (расход) и `ТоварыВНаличии` (приход, сумма) построчно;
3. правка количества → сырьё пересчитано; две правки подряд — остаток у переработчика не задвоен (`bsl-018`);
4. вторая строка в тот же документ; устаревшая версия — отказ с перечитыванием;
5. «+ услуга переработки» на документ из двух строк — распределение по весам, шапка = сумма, долг переработчику,
   себестоимость строк = сырьё + услуги строки; удаление строки сохраняет сумму шапки;
6. запреты: непроведённая передача, продукция не из ожидаемой, количество сверх ожидаемого, чужой заказ, документ
   с `СырьеИзмененоВручную`;
7. права: у `Кладовщика` нет проведения поступления → `ПравоДоступа` по роли, текст запрета ввода непустой (статически,
   как сценарий техкарт `:3199`);
8. удаление всех строк — документ помечен на удаление.

**`ПереработкаПоЗаказам`** (документ): правка шапки распределяет по весам; шапка без строк (старый код) распределяется

## Риски

1. **Деньги**: смена распределения услуг — только при заполненных строках; страховка «сумма строк ≠ шапка» → старый
   путь. Выпуск продукции не должен измениться — параметр необязательный, сценарии выпуска гоняются.
2. **Реструктуризация** двух таблиц документа: новые колонки с умолчаниями (Ложь, 0), данные не теряются; обработчик
   монопольный.
3. **`ПередЗаписью` при загрузке** не работает — обработчик пишет строки сам, в режиме загрузки.
4. **Блокировки**: порядок `ТоварыВНаличии` → `ТоварыВПереработке` из S4-B не меняется, набор строится функцией
   документа, а не копией (урок `ЗаблокироватьОстаткиПередачи`).
5. **Form.form**: самая большая форма; посторонние блоки в диффе = откат чужой правки.
6. **«ё»** в новых именах нет; пути с «ё» — `git add -u` + `git show --stat`.
