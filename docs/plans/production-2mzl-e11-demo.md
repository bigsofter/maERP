# Бриф: демо-данные производственного контура и торговли (E11, демо-часть)

## Задача

Наполнить тестовую базу `build/ib` записываемыми демо-данными, по которым видны все варианты работы документов
производственного контура 2mzl и торговли — по стадиям и статусам. На этих данных снимаются скриншоты для инструкций
maERP в базе знаний tinycio (отдельная задача в проекте tinycio). Основание — план волны `docs/plans/production-2mzl.md`,
этап E11, пункт «функциональный тест бизнес-процесса: записываемые демо-данные контура 2mzl».

Решения владельца 2026-09-14:

1. Демо-данные — **прямо в `build/ib`**.
2. Объём — **контур 2mzl + торговля**: техкарты, коммерческие предложения, заказы клиента на производство на каждой стадии и
   по каждой схеме производства, закупки под заказ, ручной выпуск и автовыпуск, реализации, возвраты, оплаты; статусы
   заказов-продаж, договоров, лидов, заявок на поиск товара, поступлений.
3. Инструкции и кейсы по схемам производства публикуются в прод tinycio сразу, со скриншотами полностью развёрнутого окна.
4. (2026-09-14, после перевода форм на закладки) Для инструкций шапка документа и его табличные части теперь на разных закладках формы (2.0.15.25, `docs/FORMS-STYLE.md`, правило 4), поэтому форма документа снимается **отдельным скриншотом на каждую закладку** — «Основное» и каждая закладка табличной части — и **у каждого скриншота своё описание**: что заполняется на закладке и что на ней видно. Одна картинка на всю форму больше не годится — вторая закладка на ней не видна.

## Что делается

- экспорт `Обработки.ТестовыеДанные.СоздатьДемоНабор()` — записывает демо-набор штатными документами (запись и проведение, без
  прямой записи регистров там, где статус пишет механизм), идемпотентно: повторный запуск набор не дублирует;
- запуск — `scripts/fixtures.sh --demo` (параметр запуска `ТестовыеДанные;<отчёт>;Демо`);
- сценарий уровня 3 `ДемоНабор` — тот же генератор в транзакции с откатом со сверкой стадий и статусов каждого кейса;
- реестр — `docs/TESTING.md` (уровень 2 для демо-набора с ручной приёмкой, уровень 3 для сценария), `docs/TESTS.xlsx`.

Тестовые сценарии E11 первой части (техкарта, полная цепочка заказа на производство и т. п.) в эту сборку не входят — они
покрыты сценариями E1–E10; остаток E11 — в плане волны.

## Границы

- Метаданные и механизмы проведения, стадий, автовыпуска не меняются; права ролей не меняются.
- Статусы, которые код не пишет штатно (у заказа-продажи «Доставлен»), прямой записью регистра не подделываются — в отчёт
  и TECHDEBT.
- Константы `ИспользоватьПроизводство` и `ИспользоватьВыпускПродукцииПриПродаже` демо-набор включает явно и сообщает об этом в
  отчёте: без них контур не показывается.
- Даты — сегодняшний день с шагом две секунды между документами контура (урок E9).
