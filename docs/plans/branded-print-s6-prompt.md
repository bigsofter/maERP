- Фаза 5: длинный перечень строк — абзацами через `ВывестиБлок` (подвал на каждой странице), не одной ячейкой.
- Фаза 5: таблицы выборок, которые отбираются `НайтиСтроки` на каждый документ, — с индексом по `Ссылка`.
