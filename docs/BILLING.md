# На какого заказчика писать время

Правило учёта — в `CLAUDE.md`, раздел «Учёт времени». Здесь — история и исключения по темам; новая тема
без строки здесь пишется на текущего клиента. Запись добавляется только по указанию владельца.

**Текущий клиент — 2MZL** (с 2026-10-06 по указанию владельца, начиная с языка печатной формы
2.0.16.18): `billto: 2MZL`. Раньше: 2026-09-30…10-01 — Afnan, 2026-10-02…10-06 —
TinyCIO. Исключение по указанию владельца: предпросмотр печати и шрифт шапок
колонок (2.0.16.21) — на TinyCIO; рабочее место закупок (2.0.16.28 и следующие сборки плана
`docs/plans/arm-purchasing.md`, 2026-10-07) — на Drissotex; список и карточка товара (проект и
этапы плана `docs/plans/nomenclature-ui.md`, 2026-10-10) — на TinyCIO; фирменные печатные формы и КП из реализации (консультация, план и фазы
`docs/plans/branded-print.md`, 2026-10-11) — на TinyCIO; ордерные склады (план и фазы
`docs/plans/warehouse-orders.md`, 2026-10-13) — на Drissotex; печать на закладках рабочего места производства (2.0.16.100, 2026-10-27) — на Drissotex; демо-данные в базе с рабочими документами (2.0.16.84,
2026-10-15, «задачи Тинисио») — на TinyCIO; история релизов в хабе TinyCIO (промпты `docs/releases-hub.md`, отправка
