# ЕстьNULL - функция языка запросов, во встроенном языке её нет

## Симптом

Форма не открывается: «Процедура или функция с указанным именем не определена
(ЕстьNULL)». Линтер BSL LS молчит, обычный CheckConfig - тоже.

## Причина

`ЕстьNULL` существует только в языке запросов. В модуле это просто неизвестное
имя, и модуль не компилируется - но ошибка вылезает лишь при обращении к форме.

## Правило

1. Значение из выборки проверять `ЗначениеЗаполнено(Выборка.Поле)`: для NULL
   она возвращает Ложь, отдельная проверка на NULL не нужна.
2. Значение по умолчанию подставлять в самом запросе: `ЕСТЬNULL(Поле, 0) КАК Поле`.
3. Такие ошибки ловит `/CheckConfig` с ключом `-ExtendedModulesCheck`: он
   разбирает модули форм, тогда как обычный прогон ограничивается конфигурацией.

## История

2026-09-02. При переносе сборки страницы «Клиент» в функцию `ТекстКлиента`
остаток долга читался как `Долг = ЕстьNULL(Долги.Долг, 0);` - в 19 модулях
форм списков. CheckConfig без расширенной проверки прошёл чисто, линтер тоже,
и ошибка вскрылась только смоком: 7 форм не открылись. Исправлено на
`Если Долги.Следующий() И ЗначениеЗаполнено(Долги.Долг) Тогда`; в тот же заход
в форме реализации восстановлена переменная `ФорматСуммы`, объявление которой
осталось в вырезанном блоке.
