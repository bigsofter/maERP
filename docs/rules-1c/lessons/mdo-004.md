# Цвет платформы не перекрашивается конфигурацией; жёлтый УНФ - тёмная тема

## Факты (проверено по выгрузке УНФ 3.0)

- Стиль «Основной» УНФ пуст: имя и синоним, никаких цветов. Жёлтый акцент на
  скриншотах УНФ - палитра ТЁМНОЙ ТЕМЫ платформы 8.5, не конфигурация.
- Конфигурации подчиняются только СВОИ элементы: надписи, поля, фоны групп,
  условное оформление списков - через элементы стиля (StyleItems). Меняешь значение
  элемента - перекрашивается всё, где он применён.
- Платформенный хром (кнопка «Провести и закрыть», подсветка раздела, вкладки)
  конфигурацией не задаётся.
- Язык платформенных строк - настройка клиента (список баз, ключ /L fr); если
  платформа установлена с другим языком, половина интерфейса будет «чужой» при
  правильных переводах конфигурации.
