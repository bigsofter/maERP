# Брендовые цвета интерфейса задаёт объект «Стиль»: FirstBrand, SecondBrand, AccentColor

## Факты (проверено экспериментом на maERP 2026-09-01)

Платформа 8.5 красит кнопки по умолчанию, подчёркивания закладок, выделения и
«важный» текст из элементов объекта конфигурации «Стиль» (DefaultStyle):

- `FirstBrand` - основной брендовый цвет (кнопка «Провести и закрыть»,
  подчёркивание активной закладки, «+ Создать»);
- `SecondBrand` - вторичный брендовый;
- `AccentColor` - акцент элементов;
- `ImportantColor` - важный текст (суммы, сроки);
- `NavigationColor` / `AuxiliaryNavigationColor` - навигация и иконки разделов;
- классические: FormBackColor, ButtonBackColor, FieldSelectionBackColor,
  FieldAlternativeBackColor («зебра»), BorderColor, шрифты.

Цвет НЕ зависит от светлой/тёмной темы клиента: заданное в стиле значение
применяется в обеих (зелёный maERP = FirstBrand #00781E в стиле; жёлтый УНФ -
их FirstBrand). Ранняя версия этого урока утверждала обратное - опровергнута.

## Ловушка: стиль в базе может расходиться с исходниками

В maERP значения стиля жили ТОЛЬКО в базе - EDT-исходник Styles/Основной.mdo
был пуст. Полная синхронизация из EDT затёрла бы бренд. Проверять дампом
(`Styles/Основной/Ext/Style.xml` в выгрузке конфигуратора) и закреплять
значения в EDT.

## Смежное

`PaletteColor` - вид метаданных 8.5 «цвета палитры»: именованные корпоративные
цвета (у УНФ 130 штук шкалами по 8 оттенков), на них ссылаются стиль и
условное оформление. Язык платформенных строк - настройка клиента (/L fr),
не конфигурации.
