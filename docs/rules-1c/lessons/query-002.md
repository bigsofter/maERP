# ИТОГИ ПО без агрегатных функций дают NULL в полях итоговой строки

## Симптом

Печатная форма с пустой шапкой либо падение на арифметике
(`Selection.TotalSomme - X` по NULL). Ошибки нет, пока код не тронет NULL.

## Причина

Код обходит выборку `ПоГруппировкам` и читает реквизиты из итоговой строки. Если в
`ИТОГИ` поле не перечислено с агрегатом, в итоговой записи его значение — NULL.

```bsl
// НЕПРАВИЛЬНО: в итоговой строке Организация, Номер, Дата = NULL
"... ИТОГИ ПО Ссылка"

// ПРАВИЛЬНО
"... ИТОГИ МАКСИМУМ(Организация), МАКСИМУМ(Номер), МАКСИМУМ(Дата) ПО Ссылка"
```

## Как проверить

Найти все `ИТОГИ ПО` и посмотреть, читает ли код из выборки верхнего уровня поля,
не перечисленные в `ИТОГИ`. Прогоном: проверка «номер документа есть в тексте
печатной формы» (строка ПОДОЗРЕНИЕ смок-теста maERP).

## История

maERP 2026-08-26: системный дефект во всех печатных формах реализации и возвратов -
шапка собиралась из итоговой строки без агрегатов. Девять запросов исправлены в
2.0.12.14-15.
