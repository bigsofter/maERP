# Псевдоним поля не может быть зарезервированным словом языка запросов

## Симптом

`{(2, 13)}: Name expected` при выполнении запроса. Компиляция модуля проходит,
CheckConfig молчит: текст запроса — строка, платформа разбирает её при выполнении.

## Причина

`ЕСТЬ`, `И`, `ИЛИ`, `НЕ`, `В`, `ВЫБОР`, `ПО` и прочие слова языка запросов не могут
быть псевдонимами полей.

```bsl
// НЕПРАВИЛЬНО - падает при выполнении
"ВЫБРАТЬ ПЕРВЫЕ 1 ИСТИНА КАК Есть ИЗ ..."

// ПРАВИЛЬНО
"ВЫБРАТЬ ПЕРВЫЕ 1 ИСТИНА КАК ЕстьДвижение ИЗ ..."
```

## Как проверить

`grep -riE "КАК (ЕСТЬ|И|ИЛИ|НЕ|В|МЕЖДУ|ВЫБОР|ПО|ИЗ|ГДЕ)[^А-Яа-яA-Za-z0-9_]" --include="*.bsl"`.
Статический анализ этого не ловит; до кода ошибка доходит только на живой базе.

## История

maERP 2026-08-27: `Справочники.Номенклатура.КомплектИспользованВДокументах` падал при
открытии карточки товара из документа. Прогон форм не поймал: у пустой ссылки функция
выходила до запроса (см. workflow-003).
