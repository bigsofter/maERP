# Правки XML вставлять по проверенной позиции, а не по первой подстроке

## Симптом

Правка «легла», XML валиден, но элемент оказался не там: подменю печати - в
командной панели ТАБЛИЦЫ вместо панели ФОРМЫ.

## Причина

Одинаковые теги (`<autoCommandBar>`, `<extInfo>`, `<items>`) встречаются на разных
уровнях вложенности. Поиск первого вхождения подстроки находит не тот узел.

## Правило

1. Якорить по уникальному признаку уровня: отступ (панель формы - ровно 2 пробела),
   родительский `name`, `id=-1`.
2. После вставки НЕМЕДЛЕННО проверить, куда легло: перечитать файл и вывести
   команды/элементы целевого узла.
3. Свойства группы лежат в ПОСЛЕДНЕМ extInfo её блока - после дочерних элементов;
   первый extInfo принадлежит первому ребёнку.
