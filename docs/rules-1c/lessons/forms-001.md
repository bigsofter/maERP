# У реквизитов формы своё пространство id, отдельное от элементов

## Симптом

EDT молча не принимает форму; объект «пропадает» из интерфейса (команда открытия
списка исчезает из меню). Ошибки при этом может не быть видно вовсе.

## Причина

В Form.form нумерация `<id>` у `<attributes>` НЕ продолжает нумерацию `<items>`.
Реквизиты нумеруются со своего ряда (1, 2, ...). Реквизит с id из ряда элементов
(например 88, потому что «максимальный id + 1») ломает форму.

```xml
<attributes><name>Список</name>...<id>1</id></attributes>
<attributes><name>ФильтрОперации</name>...<id>2</id></attributes>  <!-- не 88 -->
```

То же относится к другим коллекциям формы: команды, параметры - каждая нумеруется
отдельно.

## Как проверить

Смотреть id СОСЕДНИХ узлов той же коллекции, а не глобальный максимум по файлу.
