# EDT не перечитывает файлы, изменённые снаружи - нужен Refresh

## Симптом

Правка закоммичена, база «обновлена», а ошибка та же. Стек указывает на строки,
которых в исходниках уже нет.

## Причина

EDT держит своё состояние проекта и при импорте в базу может отдать кэшированную
копию, не заметив внешних правок файлов.

## Правило

1. После внешних правок - Refresh (F5) проекта в EDT, потом обновление базы.
2. Не доверять «обновил»: сверять СОДЕРЖИМОЕ базы выгрузкой
   `1cv8 DESIGNER /DumpConfigToFiles <каталог> -format Hierarchical` и грепом по
   спорным строкам. Это единственная точная проверка, что в базе.
3. EDT в агентном режиме держит базу - пакетный конфигуратор получит
   «база открыта Конфигуратором». Просить закрыть EDT перед пакетными операциями.

## История

maERP 2026-08-31: две итерации «обновил - та же ошибка» из-за непрочитанных правок;
диагностировано сравнением стека с исходниками, подтверждено выгрузкой.
