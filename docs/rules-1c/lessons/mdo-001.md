# Обработке в интерфейсе нужен useStandardCommands

## Симптом

Обработка размещена в подсистеме/командном интерфейсе, права выданы - а в меню её
нет. Ни ошибки, ни предупреждения.

## Причина

Без `<useStandardCommands>true</useStandardCommands>` у обработки НЕ СУЩЕСТВУЕТ
стандартной команды «Открыть» (`DataProcessor.X.StandardCommand.Open`) - размещать
в интерфейсе нечего, записи в .cmi ссылаются в пустоту.

## Правило размещения обработки в разделе (полный набор)

1. `<useStandardCommands>true</useStandardCommands>` в .mdo обработки;
2. `<content>DataProcessor.X</content>` в .mdo подсистемы-раздела;
3. запись в CommandInterface.cmi раздела (группа, видимость) - опционально для
   порядка; видимость даёт уже состав подсистемы;
4. право Use/View в ролях.

Сверять с работающим образцом в той же конфигурации (в maERP - ЗагрузкаИзExcel),
а не собирать по памяти.
