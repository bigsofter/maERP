# Чек-лист перед коммитом правок Form.form

## Правило

После любой правки Form.form, до передачи владельцу:

1. **XML валиден**: `python3 -c "import xml.dom.minidom as m; m.parse('...')"`.
2. **Пути данных существуют**: каждый `<segments>Объект.X</segments>` сверен с .mdo
   (см. forms-002).
3. **Вставка легла куда надо**: перечитать целевой узел и вывести его состав
   (см. forms-003).
4. **id в своём пространстве**: соседние узлы той же коллекции (см. forms-001).
5. **Структура групп**: дерево формы (скрипт-принтер дерева) глазами.
   Плюс частотный аудит тегов extInfo против остальных форм конфигурации -
   ловит выдуманные теги, которые EDT молча глотает, а клиент на них падает
   (см. workflow-005).
6. `scripts/lint.sh` без новых замечаний, `scripts/refcheck.py` чист.

Чего эти проверки НЕ ловят: несуществующие директивы компиляции (bsl-002), коллизии
имён с глобальным контекстом (bsl-001), обращения к реквизитам формы как к объекту
(bsl-003). Их ловит только CheckConfig + открытие формы на базе - поэтому после
импорта владельцем гонять смок, а не считать работу сданной по линтеру.

## История

секунда владельца на «обновил - не работает» дороже всех проверок вместе.
