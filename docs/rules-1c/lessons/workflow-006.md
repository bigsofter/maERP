# «Загрузить из базы» в EDT создаёт проект в воркспейсе и может опустошить git-каталог

## Симптом

После «Загрузить конфигурацию из информационной базы» `git status` показывает
удаление ВСЕХ файлов `src/cf` (тысячи `D`), а изменений в репозитории нет.

## Причина

Мастер импорта не грузит конфигурацию в существующий проект, а создаёт НОВЫЙ
проект в воркспейсе EDT (`~/EDT/<workspace>/<имя>/`). Если при этом старый
одноимённый проект удаляется «вместе с содержимым», EDT физически стирает файлы
из линкованного git-каталога. Репозиторий спасает только сам git.

## Правило

1. После любого импорта из базы владельцем — первым делом `git status`.
   Массовые `D` лечатся `git checkout -- .`; ничего не коммитить до восстановления.
2. Результат импорта искать в воркспейсе EDT, а не в репозитории. Переносить
   оттуда в `src/cf/src` только целевые объекты точечным копированием — иначе
   дифф утонет в перегенерации всей конфигурации.
3. После переноса напомнить владельцу вернуть привязку EDT к проекту в
   `src/cf`: воркспейс-копия — тупиковая ветка, правки в ней в git не попадают.

## Как EDT сериализует стиль и картинки (для точечного переноса)

- Элементы объекта «Стиль» (цвета `FirstBrand`, `FormBackColor` и т.д.) лежат
  НЕ в `Основной.mdo`, а в соседнем файле `Style.style`
  (`<items xsi:type="style:ColorStyleItem">` с RGB-компонентами).
- Общая картинка с вариантами — `Picture.zip` рядом с `.mdo`: внутри `icon.svg`
  и `manifest.xml` с `<PictureVariant name="icon.svg" screenDensity="ldpi"
  interfaceVariant="version8_5" theme="" isTemplate="true"/>`; `isTemplate`
  включает перекраску SVG платформой под тему. Одиночный `Picture.png`
  при этом заменяется архивом — старый файл удалить.

## История

2026-09-01. Стиль «моно-янтарь» и 9 SVG-иконок разделов были заведены прямо в
стендовой базе `build/ib-style` (частичной загрузкой XML-дампа). Чтобы втянуть
их в исходники, владелец выполнил в EDT «Загрузить из базы» — EDT пересоздала
проект в `~/EDT/maERP/maERP/` и удалила все 2498 файлов `src/cf` из
репозитория. Дерево восстановлено `git checkout -- .`, из воркспейса перенесены
только `Styles/Основной/Style.style` и 9 каталогов `CommonPictures/*`
(Picture.png → Picture.zip). Заодно выяснилось, где EDT хранит элементы стиля:
в `Style.style`, который до того ни разу не редактировался руками.
