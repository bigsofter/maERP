# Имя своей процедуры не должно совпадать с глобальным методом платформы

## Симптом

CheckConfig: `En espera del símbolo ')'` / «ожидается )» на строке вызова своей
функции. BSL LS молчит: для него вызов синтаксически корректен.

## Причина

Если в модуле объявлена функция с именем глобального метода платформы, но с другой
сигнатурой, вызовы с параметрами резолвятся в платформенный метод. `ОписаниеОшибки()`
- глобальный метод без параметров; своя `ОписаниеОшибки(Информация)` не вызовется.

```bsl
// НЕПРАВИЛЬНО
Функция ОписаниеОшибки(Информация) ...
// ПРАВИЛЬНО
Функция ОшибкаОднойСтрокой(Информация) ...
```

## Как проверить

Перед вводом нового имени поискать его в синтакс-помощнике/глобальном контексте.
Ловится только CheckConfig на базе - гонять его после каждого нового имени уровня
модуля.

## История

maERP 2026-08-31: функция `ОписаниеОшибки` в форме СмокТеста. Также известно:
`МенеджерОбработкиОшибок` в клиентском контексте 8.5.1 не определён - используются
устаревшие глобальные методы с комментариями BSLLS-off.
