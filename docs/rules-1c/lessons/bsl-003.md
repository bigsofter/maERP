# Реквизит формы и реквизит объекта - разные пространства данных

## Симптом

`El campo del objeto no encontrado (X)` при обращении `Объект.X` или `Документ.X`.

## Причина

Вычисляемые поля (срок оплаты по договору, суммы оплат, финрезультат) часто живут
реквизитами ФОРМЫ, а не объекта. В `&НаКлиентеНаСервереБезКонтекста`-функции данных
формы нет - реквизит формы передаётся параметром.

```bsl
// НЕПРАВИЛЬНО (СрокОплаты - реквизит формы)
Функция Текст(Документ)  ... Документ.СрокОплаты ...
// ПРАВИЛЬНО
Функция Текст(Документ, СрокОплаты) ...
```

## Как проверить

Перед обращением `Объект.X` сверить X со списком реквизитов в .mdo документа, а не
со списком `<attributes>` формы. См. также forms-002 про пути данных.
