# Список выбора без представлений на всех языках показывает само значение

## Симптом

Тумблер знака сравнения на французском интерфейсе выводит «0 1 2» вместо
«> < =». В русском сеансе всё правильно.

## Причина

В `choiceList` элемента формы представление (`presentation`) задано только для
одного языка. Платформа не подставляет представление другого языка и выводит
само значение элемента списка - число.

## Правило

Каждый `choiceList` заполняется на все языки конфигурации (ru, fr, en, es), даже
когда текст одинаковый: символы «&gt;», «&lt;», «=» переводить не нужно, но
записать их нужно четырьмя блоками `presentation`. То же касается списков выбора,
собираемых кодом: `СписокВыбора.Добавить(Значение, НСтр("ru = '...'; fr = ..."))`.

## История

2026-09-02. Фильтры по сумме и долгу в панели сведений получили тумблер знака
с представлением только на русском. На французском клиенте владельца тумблер
показал «0 1 2». Исправлено разом во всех 42 списках; заодно тумблер и поле
суммы объединены в одну горизонтальную группу - знак слева, значение справа.
