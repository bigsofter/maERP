# Путь данных поля должен указывать на существующий реквизит

## Симптом

EDT при импорте в базу: `Ruta incorrecta a los datos: "Объект.X"`. Импорт всей
конфигурации отменяется.

## Причина

`<segments>Объект.X</segments>` требует реквизита X у ОБЪЕКТА. Частая ловушка:
реквизит есть в табличной части, но не в шапке (`СуммаСкидки` у строк ТЧТовары
есть, у документа - нет).

## Как проверить

Перед коммитом формы - механическая сверка: собрать все
`<segments>Объект.([А-Яа-я\w]+)</segments>` и проверить каждое имя по .mdo
документа (реквизиты + табличные части + стандартные: Ссылка, Номер/Number,
Дата/Date, Проведен, RegisterRecords).
