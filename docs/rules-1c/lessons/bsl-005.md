# API метаданных: свойство называется Использование, коллекции обходятся циклом

## Симптом

`El campo del objeto no encontrado (ИспользованиеРеквизита)` или
`Recepción de un elemento por el índice para el valor no determinada`.

## Причина

Две частые ловушки API метаданных:

1. Свойство реквизита справочника называется `Использование`;
   `ИспользованиеРеквизита` - имя СИСТЕМНОГО ПЕРЕЧИСЛЕНИЯ его значений
   (`Метаданные.СвойстваОбъектов.ИспользованиеРеквизита.ДляЭлемента`).
2. Коллекция `Описание.Владельцы` не поддерживает доступ по индексу `[0]` -
   только обход `Для Каждого`.

```bsl
// ПРАВИЛЬНО
ТолькоДляЭлемента = Метаданные.СвойстваОбъектов.ИспользованиеРеквизита.ДляЭлемента;
Если Реквизит.Использование = ТолькоДляЭлемента Тогда ...
Для Каждого ОписаниеВладельца Из Описание.Владельцы Цикл ... Прервать; КонецЦикла;
```

## Как проверить

Ошибки видны только на живой базе. Новый код по метаданным прогонять фикстурой/смоком
до передачи владельцу.
