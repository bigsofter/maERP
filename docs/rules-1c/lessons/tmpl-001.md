# Ячейка макета: заполнение Text не принимает параметр

## Симптом

Печать падает: «Поле объекта не обнаружено» при присваивании
`Область.Параметры.X = ...`.

## Причина

Ячейка .mxlx может содержать ИМЯ параметра, но иметь `fillType=Text` - тогда
параметра не существует. Код, пишущий в параметр, падает.

Текстовые ячейки-шаблоны вида `Табель ... №[Номер] за [Период]` дают параметры
Номер/Период только при заполнении «Шаблон».

## Как править

В формате ячейки поставить `<fillType>Parameter</fillType>`. Формат ячейки задаётся
ссылкой `<f>N</f>` на список `<format>` в конце документа: N указывает на
formats[N-1]. Новый формат ДОБАВЛЯТЬ В КОНЕЦ списка - тогда чужие индексы не
сдвигаются.
