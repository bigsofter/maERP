# Новую XML-конструкцию собирать по работающему образцу из этой же конфигурации

## Правило

Прежде чем писать незнакомый узел (подменю, тумблер, панель, страница, картинка
закладки) - найти РАБОТАЮЩИЙ образец: сначала в своей конфигурации, затем в
выгрузке УНФ (build/unf_14_123). Скопировать структуру образца, заменить имена.
Не найден образец - не собирать по памяти: сериализация EDT не очевидна
(порядок тегов, пространства значений, ссылки вида Enum.X.EnumValue.Y,
StdPicture против CommonPicture).

Форматы значений в choiceList/параметрах: `core:ReferenceValue`,
`core:NumberValue`, `core:StringValue`, `core:BooleanValue` - подсмотреть в
готовых формах.

## История

maERP 2026-08-31: конструкции, собранные по образцу (тумблер, кнопки, подменю),
вставали с первого раза; собранные по памяти (директива, id, пути) - падали.
