# Правила разработки 1С

Подмножество правил из [comol/ai_rules_1c](https://github.com/comol/ai_rules_1c)
(взято 2026-08-21, ветка main). Скопированы только содержательные правила
разработки: стиль кода, структура модулей, формы, запросы, регистры, СКД,
блокировки и транзакции, антипаттерны, асинхронность, журналирование.

Что осталось за бортом и почему:

- адаптеры под IDE, инсталляторы, MCP-серверы и playbook'и — у нас свой
  тулчейн: EDT + BSL LS (`scripts/lint.sh`), см. `docs/EDT-SETUP.md`;
- правила про субагентов, оркестрацию и модели — процессные, не про 1С;
- PowerShell-скрипты — Windows-специфика.

Внутри файлов встречаются ссылки на `AGENTS.md`, `.dev.env`, MCP-вызовы и
skill `1c-metadata-manage` — в этом проекте их нет, такие места читать как
«сделай то же самое своим инструментом».

Рядом лежит `lessons/` — правила, выведенные из реальных ошибок maERP
(свой README и машинный манифест `rules.json`, структура готова под MCP-сервер).
При работе с Form.form, .mdo, запросами и макетами уроки смотреть ПЕРВЫМИ:
они конкретнее общих стандартов и каждый подтверждён пойманной ошибкой.

Приоритет при конфликте: `CLAUDE.md` проекта → эти правила → ИТС.
Правила применяются к новому коду; существующий код приводится к ним
по мере рефакторинга, а не массовой правкой.
