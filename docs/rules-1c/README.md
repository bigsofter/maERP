# Чужие справочники по 1С

Правила разработки maERP живут в наборе **tiny1C** — https://github.com/bigsofter/tiny1C (направления `core` и
`greenfield`). Он подключается MCP-сервером `tiny1c` (`.mcp.json` в корне проекта): перед правкой Form.form, .mdo,
запросов и макетов — `checklist`, по тексту ошибки — `lookup_rule`. Каждое правило там подтверждено пойманной ошибкой
и называет, чем оно ловится.

Здесь остался один заимствованный корпус — `unica/`: снимок справочников
[IngvarConsulting/unica](https://github.com/IngvarConsulting/unica) под платформу 8.3.27 и форматы платформенного XML
(LGPL-3.0-or-later, свой README и LICENSE, не правится). Нужен, когда работа идёт на 8.3 или с выгрузкой конфигуратора:
уроки tiny1C написаны из ошибок 8.5.1 в EDT-проекте.

Приоритет при конфликте: `CLAUDE.md` проекта → правила tiny1C → `unica/` → ИТС.

Подмножество правил comol/ai_rules_1c, лежавшее здесь с 2026-08-21, удалено 2026-11-21 по решению владельца: проект
перешёл на собственные правила, а у исходного репозитория нет файла лицензии.
