# Техдолг

Осознанно отложенные работы. Формат: что, почему отложено, чем грозит.

## Интерфейс

- **Видимость разделов по ролям** — на паузе по решению от 2026-08-21.
  Сейчас все разделы командного интерфейса видны всем ролям (фрагменты
  видимости есть только для MobileClient). Вернуться, когда роли начнут
  реально использоваться при внедрениях: составить матрицу «роль → разделы»
  и проставить в `Configuration/CommandInterface.cmi`.
- **Проход по ~400 формам в интерфейсе 8.5** — формы без
  `preferableInterface`; негодные точечно закреплять за «Такси».
- **`mainSectionPicture` пустая** — главный раздел без картинки; нужен
  логотип решения (новая общая картинка).

## Решения, которые надо принять

- **Судьба `ОбменССайтом`** — «атавизм»: 2 плана обмена, обработка на
  5,5 тыс. строк, треть ошибок статанализа. Выпилить или чинить.
- **Судьба `МенеджерОборудования*`** — 5 модулей, ~2100 замечаний BSL LS,
  вызовы несуществующих методов БСП. Нужно ли торговое оборудование.
- **Хардкод пароля** скрытого администратора `tinycio-1c` в
  `ФормаПервогоЗапуска` — репозиторий публичный. Генерация при первом
  запуске / аутентификация ОС / выделенная роль.

## Код

- **`Reports/КарточкаСубконто/ManagerModule.bsl:543`** — отладочный
  безусловный `Возврат` отключает коррекцию показателя «Контроль».
  Включать после проверки на данных.
- **Регистр `НДСПродажи` никем не заполняется** — менеджерный
  `СформироватьДвижения` есть, вызовов нет; налоговые накладные пишут
  только ТоварыВНаличии/ДенежныеСредства/Взаиморасчёты.
- **`Документ.Взаимодействие`** — форма использует `ОткрытьФормуМодально`
  при `modalityUseMode = DontUse`; перевести на асинхронные открытия
  (`docs/rules-1c/async-methods.md`).
- **`Справочник.Банки`: загрузка классификатора с rbc.ru** — виндовые
  разделители путей, `КопироватьФайл` по http; мертво на macOS/Linux
  сервере и бессмысленно вне РФ. Выпилить или заменить источник.
- **51 обработчик записи без проверки `ОбменДанными.Загрузка`** — мина
  под любой обмен/РИБ.
- **Запросы в циклах** (13 мест), **виртуальные таблицы без параметров**
  (27), **`НайтиПоНаименованию`/`НайтиПоКоду` на сервере** (86) — этап
  производительности.
- **Опечатки в именах метаданных**: `ВзаиморасчётыСПоcтавщикамиНалоговый`
  (латинская «c»), элементы стиля `BottonBackgroundColor`, `BottonFont`,
  `ButonTextColor`; всего 105 имён со смесью алфавитов. Переименование
  через рефакторинг EDT, отдельными коммитами.
- **NFC/NFD в путях git** — часть кириллических путей хранится в NFD
  (наследие macOS). Привести к NFC одним переименовывающим коммитом.

## Найдено при сравнении с drissotex (2026-08-22)

Подробности и план переноса — `docs/MERGE-DRISSOTEX.md`, раздел
«Побочные дефекты на нашей стороне».

- **`CommonForms/ИнтерфейсКлиент/Module.bsl:13`** — читает
  `ПараметрыСеанса.Контрагенты`, которого нет (есть `Контрагент`). Падение
  при открытии формы.
- **Синоним `СтатьяДДС` = «Артикул»** в ПКО, РКО, ПБДС, СБДС,
  `ПрочиеРасходы(Возврат)`, `ПоступлениеДополнительныхРасходов`, регистре
  `ДвиженияДенежныхСредств` — ошибка перевода (fr *article*).
- **Строки формата в макетах переведены как текст** (`ЧДЦ=2` → `CDT=2`,
  `ДФ=dd.MM.yyyy` → `DF = JJ. MM. yyyy`) в 10 макетах чеков, ордеров и
  актов сверки — числа и даты выводятся неверно.
- **«Наименование» → «Товар»** глобальной заменой в ~18 формах, где речь не
  о товаре (в т. ч. `Хозрасчетный/ФормаСчета`).
- **`ЗаказПокупателя/ПечатьКоммерческоеПредложениеА4`** вызывает
  `PrintDevisBL` с пятым аргументом, которого нет в сигнатуре.
- **Свойства конфигурации** `BriefInformation`, `DetailedInformation`,
  `Copyright`, `VendorInformationAddress`, `Vendor`, `Version` — заглушки
  «1/2/3/4/6/7».
- **`ОперацияБух/ФормаДокумента`**: у `ХозрасчетныйПодразделениеДт/Кт` нет
  `DataPath` — проверить привязку в EDT.
- **Дубли без потребителей**: функции хранилищ настроек в
  `ОбщегоНазначения` (497 строк) продублированы локально в
  `ГрупповоеИзменениеРеквизитов/Форма`; `ДлительныеОперации.ЗапуститьВыполнениеВФоне`,
  `ОбщегоНазначенияКлиентСервер.СкопироватьРекурсивно` и соседи не
  вызываются.
- **`ОбщегоНазначенияВызовСервера.ПолучитьИмяПринтераЧековНаСервере`** —
  директива `&НаСервере` в общем модуле.

## Платформа

- **Режим совместимости 8.3.23** — поднять до актуального отдельной
  задачей с регрессионным прогоном.
- **Английская терминология**: коллизия `Товар = Product` и
  `Продукция = Finished product`; предложено `Goods` для «Товар».
