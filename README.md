# maERP

**Русский** · [English](README.en.md) · [Français](README.fr.md) · [Español](README.es.md)

maERP — тиражная система управления предприятием на платформе 1С:Предприятие 8.5: продажи, закупки, склад,
производство, розница с кассой, деньги и бухгалтерский учёт в одной базе. Разработчик — TinyCIO. Интерфейс и печатные
формы — на русском, французском, английском и испанском языках; налоговый контур настроен под Марокко и расширяется
ставками страны при создании базы.

Готовые файлы поставки (`.cf` и `.cfu`) лежат в разделе [Releases](https://github.com/bigsofter/maERP/releases),
история изменений — в [docs/CHANGELOG.md](docs/CHANGELOG.md).

## Что умеет

| Раздел | Возможности |
|---|---|
| Продажи | Коммерческие предложения, заказы клиентов, расходные и налоговые накладные, возвраты, скидки суммой и процентом, контроль кредита и запрет отгрузок, закладка «Товары» со строками документов прямо в списке |
| Розница | Рабочее место кассира, кассовые смены, чеки, прайс-чекер, этикетки и ценники, потребности торговых точек, отрасль «Телефоны и аксессуары» с учётом по серийным номерам (IMEI) |
| Закупки | Заказы поставщикам, тендеры, поступления, возвраты поставщикам, планирование закупок по потребности, рабочее место закупок |
| Склад | Перемещения, ордерные склады, инвентаризация с описью и сличительной ведомостью, партии и их прослеживаемость, мобильная приёмка и пересчёт |
| Производство | Технологические карты, производство под заказ клиента, требования-накладные, выпуск, передача в переработку по нескольким заказам, себестоимость продукции, управление станками: загрузка, простои, обслуживание, эффективность (OEE) |
| Деньги | Касса и банк, взаиморасчёты с покупателями и поставщиками, документы в валюте, просроченные долги, движение денежных средств |
| Бухгалтерия и налоги | План счетов и проводки, раздельный управленческий и налоговый учёт, зоны НДС и освобождение, удержание НДС у источника, реестры налоговых накладных |
| Зарплата и кадры | Сотрудники, табель рабочего времени, начисления и ведомости |
| Сервис | Обмен между базами maERP через каталог или HTTPS, загрузка из Excel, дополнительные реквизиты, права по ролям, окно «Что нового», автоматическое обновление данных базы |

В конфигурации 54 вида документов, 70 отчётов и 26 ролей. Печатные формы — фирменные, с логотипом организации,
предпросмотром и выводом на языке контрагента.

## Установка и обновление

Для работы нужна платформа 1С:Предприятие 8.5.1 и её лицензии — они приобретаются у фирмы «1С» и её партнёров
и в состав maERP не входят.

- **Новая база.** Создать информационную базу из файла `maERP-<версия>.cf`. При первом входе открывается мастер:
  организация, страна, отрасль, пользователи.
- **Обновление.** Загрузить `maERP-<версия>.cfu` (обновление с опубликованных релизов) или полный `.cf`.
  При первом входе администратора программа сама обновит данные и покажет окно «Что нового».
- **Развёртывание без интерфейса** (сервер, веб-клиент) — [docs/DEPLOY.md](docs/DEPLOY.md).

Перед обновлением рабочей базы сделайте её резервную копию.

## Для разработчиков

Исходники хранятся в формате 1C:EDT — дерево текстовых файлов (`.mdo` — метаданные, `.bsl` — код модулей).
Файл `.cf` — артефакт сборки и в репозиторий не попадает.

```
src/cf/      EDT-проект конфигурации
docs/        среда, тесты, выпуск релизов, планы
scripts/     сборка и проверки поверх CLI платформы
tools/       перенос данных с прежней редакции
build/       артефакты сборки (в git не попадает)
```

| Что | Версия |
|---|---|
| Платформа 1С | 8.5.1.1150 |
| 1C:EDT | см. [docs/EDT-SETUP.md](docs/EDT-SETUP.md) |
| Java | 17, поставляется вместе с EDT |

Ветка разработки — `develop`, в `main` попадают только релизные состояния. Сборка поставки:

```bash
scripts/ib-sync.sh build/ib            # EDT-проект -> база сборки
scripts/smoke.sh                       # проверка конфигурации и смок-тесты
scripts/dist-build.sh <версия>         # база -> build/dist/maERP-<версия>.cf и .cfu
```

Правила проекта — [CLAUDE.md](CLAUDE.md), тесты — [docs/TESTING.md](docs/TESTING.md), выпуск версии —
[docs/RELEASING.md](docs/RELEASING.md) и [docs/RELEASE.md](docs/RELEASE.md).
