# maERP

Тиражное решение на платформе 1С:Предприятие 8.5. Собственная конфигурация,
разработка ведётся напрямую в основной конфигурации.

## Как это устроено

Исходники хранятся в формате 1C:EDT — дерево текстовых файлов (`.mdo` —
метаданные, `.bsl` — код модулей). Именно они версионируются в git. Файл `.cf`
считается артефактом сборки, а не исходником, и в репозиторий не попадает.

```
src/cf/      EDT-проект основной конфигурации
src/ext/     EDT-проекты расширений
docs/        настройка среды, архитектура, процесс релиза
scripts/     сборка и проверки поверх CLI платформы
build/       артефакты сборки (в git не попадает)
```

## Требования

| Что | Версия | Где |
|---|---|---|
| Платформа 1С | 8.5.1.1150 | `/opt/1cv8/8.5.1.1150` |
| 1C:EDT | см. `docs/EDT-SETUP.md` | `/Applications/1C/1CE` |
| Java | 17 | поставляется вместе с EDT |

## Быстрый старт

Настройка среды с нуля — [docs/EDT-SETUP.md](docs/EDT-SETUP.md).

Сборка поставки:

```bash
scripts/edt-export.sh          # EDT-проект  -> build/xml
scripts/xml-load.sh            # build/xml   -> база сборки
scripts/dist-build.sh 1.0.0    # база        -> build/dist/maERP-1.0.0.cf
```

Процесс выпуска версии — [docs/RELEASE.md](docs/RELEASE.md).
