# maERP (1С:Предприятие)

ERP на платформе 1С:Предприятие 8.3: универсальное учётное **ядро** + **отраслевые расширения** (оптика, б/у телефоны, транспорт). Развёртывание on-premise на клиента. Подробности — в [`ARCHITECTURE.md`](ARCHITECTURE.md).

## Структура репозитория

```
maERP/
├── ARCHITECTURE.md          архитектура решения на 1С
├── CLAUDE.md                правила для AI-ассистентов (Claude Code / Cline / Roo Code)
├── .bslls.json              настройки линтера BSL Language Server
├── .gitignore .gitattributes .editorconfig
├── src/                     ИСХОДНИКИ ЯДРА — выгрузка основной конфигурации (XML конфигуратора)  ← пусто, заполняется первичной выгрузкой
├── extensions/              отраслевые расширения (.cfe), исходники в файлах
│   ├── optical/             оптика: медкарта, рецепты, диоптрии
│   ├── usedphones/          б/у телефоны: IMEI, % батареи, история ремонта
│   └── transport/           транспорт: маршруты, водители, путевые листы
├── scripts/                 выгрузка / сборка / деплой / линт
├── tests/                   автотесты (YaXUnit / Vanessa Automation)
└── 1c-dev-setup/            руководство по среде разработки + шаблоны конфигов
    ├── README-1C-DEV.md
    └── starter-kit/         шаблоны .mcp.json и .vscode (создаются вручную, см. ниже)
```

## С чего начать

1. Настроить среду разработки по [`1c-dev-setup/README-1C-DEV.md`](1c-dev-setup/README-1C-DEV.md).
2. Создать вручную `.vscode/` и `.mcp.json` из [`1c-dev-setup/starter-kit/`](1c-dev-setup/starter-kit/) (эти файлы среда не даёт записать автоматически из соображений безопасности).
3. Сделать первичную выгрузку конфигурации в `src/` (см. `scripts/dump-from-base.bat`).

## Топология

- **Mac** — разработка: 1C:EDT, VSCode, AI-ассистент, локальная файловая dev-ИБ.
- **Windows-сервер** — 1С:Сервер + СУБД: живая база, test, prod.
