# Генератор формы рабочего места закупок

`src/cf/src/DataProcessors/АРМЗакупки/Forms/Форма/Form.form` собрана скриптом `gen.py` из проверенных узлов формы
рабочего места производства (оболочки групп, таблица значений как образец таблицы и колонки, поле фильтра, пагинатор,
панель фильтров, команды) — урок tiny1C workflow-005. Id перенумеровываются в трёх независимых пространствах: элементы,
реквизиты, команды (forms-001, forms-018).

Источник правды — `Form.form` в `src/cf`; генератор нужен, чтобы следующая правка формы не начиналась с нуля.

```bash
cd scripts/formgen/zakupki
python3 gen.py > ../../../src/cf/src/DataProcessors/АРМЗакупки/Forms/Форма/Form.form   # сборка
python3 gen.py | diff - ../../../src/cf/src/DataProcessors/АРМЗакупки/Forms/Форма/Form.form   # сверка
```

Образец читается из текущей формы рабочего места производства: её правка меняет и вывод генератора. Перед
перегенерацией — сверка с репозиторием; после — Refresh в EDT, `scripts/listcheck.py`, `scripts/colfont.py`, смок и
снимок окна (форма, собранная скриптом, может уронить клиент там, где ручная — нет; forms-009).

| Сборка | Что в форме |
|---|---|
| 2.0.16.28 | закладка «Заказы поставщикам»: таблица страницы заказов, пагинатор с легендой, панель фильтров; нижние закладки «Товары», «Поступления», «Оплаты» (с сальдо), «Документы» — только чтение; команды «Создать», «Обновить» |
| 2.0.16.29 | «Изменить статус ▾» над заказами (подменю и команды — как у заказов рабочего места производства, выделение нескольких строк); закладка «К поступлению» (накладная поставщика, флажки строк, «Оформить поступление»); «Товары» и «Поступления» с вводом строк — оболочка таблицы и колонки ввода по таблице «Заказы поставщику» рабочего места производства, колонка-флажок — по форме «Групповое изменение реквизитов» |
